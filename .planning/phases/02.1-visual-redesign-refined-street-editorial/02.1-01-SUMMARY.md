## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Tailwind v4 `@theme` parser failed on inline comments containing glob-like `*` + `/` sequences**
- **Found during:** Task 3 (first `npx astro build`).
- **Issue:** The build failed with ``@theme blocks must only contain custom properties or @keyframes``. Root cause: descriptive comments inside the `@theme` block (e.g. `bg-*/text-*/border-*` and `--font-* → font-*`) contain `*` immediately followed by `/`, which the Tailwind v4 CSS parser mis-reads as a premature comment close, leaving stray tokens inside `@theme`.
- **Fix:** Rewrote the affected `@theme` comments as plain prose with no `*`/`/` glob sequences. No token values changed.
- **Files modified:** `src/styles/theme.css`
- **Commit:** 1cd0f84 (folded into Task 3, since theme.css was authored in Task 2 and the parser only runs at build time in Task 3)
