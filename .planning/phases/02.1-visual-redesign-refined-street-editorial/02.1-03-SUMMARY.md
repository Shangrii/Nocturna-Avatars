# Phase 02.1 Plan 03: Dedicated Pages Re-skin Summary

Re-skinned the dedicated pages (/servicios, /galeria, /terminos, 404) to the Refined Street
Editorial system, applying the shared ink/paper CSS from Plan 02. Terms page becomes a paper
reading column (760px, 1.8 line-height). The 404 gets plain functional copy and centered text.
Workflow step icons on the landing are centered. A non-functional gallery filter affordance was
introduced then removed per UAT feedback.

## What Was Built

- **Task 1 (`a6c608e`):** `GalleryPage.astro` updated with editorial header + EmptyState +
  category-filter chip row (visual-only, `aria-disabled`/`inert`). `ServicesPage.astro` already
  consumed the Plan 02 re-skinned classes correctly — no structural changes needed.
- **Task 2 (`3fd9a2d`):** Rewrote `src/styles/terms.css` to the paper editorial system —
  `var(--color-paper)` field via `.section--surface`, 760px column, `var(--lh-legal)` 1.8
  line-height, Space Mono red block numbers as the single accent, hairline 1px separators,
  0px radii. `TermsPage.astro` gains `.section--surface` class for the paper field. The 404
  already consumed re-skinned `sections.css` `.notfound*` rules from Plan 02; no source edits
  needed to the page itself.
- **UAT fixes (`712e376`):** Four corrections applied post human-verify checkpoint:
  1. Workflow step icons centered (`align-items: center` on `.workflow-step`, `justify-content:
     center` on `.step-icon`, `text-align: center` on `.step-label`).
  2. Gallery filter chips removed from `GalleryPage.astro` — confusing without data.
  3. Terms column width reverted from `70ch` back to `760px`; paper field + 1.8 lh retained.
  4. 404 heading de-themed: "Página no encontrada" replaces "Esta página se perdió en la noche";
     `.notfound-body` / `.notfound-body--alt` get `margin: 0 auto` for proper centering.
