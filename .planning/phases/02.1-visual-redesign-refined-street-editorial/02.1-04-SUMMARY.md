Refined Street Editorial system. All chrome.ts behavior hooks preserved. Full-site build verified
with dc-trigger on every chrome-bearing page. Phase 02.1 closed with all six ROADMAP success
criteria confirmed by human QA.

## What Was Built

- **Task 1 (`cee72bc`):** `chrome.css` re-written to the editorial system:
  - 0px radii on nav CTA, lang trigger, lang menu, dc-modal card, dc-icon
  - `.nav.scrolled` backdrop raised to 0.95 opacity so off-white text stays AA over both ink and paper sections

  - `footer-copy` uses CSS `opacity: 0.4` on `var(--color-white-dim)` (no raw rgba hex)

  - `.nav--hidden` selector added (chrome.ts toggles it for hide-on-scroll)
  - `nav-link::after` added to the `@media (prefers-reduced-motion: reduce)` block
  - All 23 chrome selectors retained; chrome.ts hooks keep matching

- **Task 2 (`2133e0c`):** Sweep + build:
