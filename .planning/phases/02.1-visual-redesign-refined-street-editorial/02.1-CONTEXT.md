# Phase 02.1: Visual Redesign — Refined Street Editorial - Context

**Gathered:** 2026-06-30
**Status:** Ready for planning
**Source:** PRD Express Path (docs/superpowers/specs/2026-06-30-website-redesign-design.md)

<domain>
## Phase Boundary

A pure **visual + structural re-skin** of the existing Nocturna Avatars site to the "Refined
Street Editorial" look, layered on top of the Phase 2 motion base. Graffiti becomes a *signature
accent* over a disciplined editorial system: oversized Space Grotesk type, generous whitespace,
clean grid, red used surgically, and a navy "ink" / off-white "paper" section rhythm.

**In scope:** Tailwind v4 integration; new type system; new color/surface tokens; restyle of hero,
all landing sections, `/servicios`, `/galeria`, `/terminos`, 404, and chrome (nav/footer/floating
CTA/lang switcher); removal of the custom cursor; landing section reorder (featured gallery above
about).

**Out of scope:** copy/content changes, i18n logic, the Discord-driven gallery automation, the
catalog data model/pricing, the legal text itself, and any new functional features. The motion
architecture (`src/scripts/motion/*`) stays — only `cursor.ts`/`cursor.css` are removed; the rest
is re-skinned, not rewritten.
</domain>

<decisions>
## Implementation Decisions

### Tech / Build
- **D-01:** Add **Tailwind v4** via the `@tailwindcss/vite` plugin in `astro.config.mjs` (NOT the
  deprecated `@astrojs/tailwind`). Global CSS uses `@import "tailwindcss";`. Site stays Astro
  **static** output → GitHub Pages, with the existing **CNAME preserved**. No React, no shadcn.
- **D-02:** Port the brand tokens into a Tailwind v4 **`@theme`** block so they become first-class
  utilities (`bg-ink`, `bg-paper`, `text-red`, `font-display`, `font-tag`, `font-mono`). Retire
  `src/styles/tokens.css` once its values live in `@theme`. Keep `global.css` for resets,
  `@font-face`, and the film-grain overlay.
- **D-03:** Migration is **incremental** — add Tailwind + `@theme` alongside existing CSS first
  (nothing breaks), then convert component-by-component, deleting each component's old CSS as it is
  converted. The site stays building/shippable at every step.

### Typography
- **D-04:** Introduce **Space Grotesk** (700) as the oversized editorial **display** workhorse —
  hero tagline + section titles, uppercase, tight tracking (~`-0.02em`), line-height 0.9–1.0.
  Loaded via Google Fonts self-hosted/subset with `font-display: swap`; preload only the
  hero-critical face.
- **D-05:** Demote the graffiti face ("A Another Tag" / Permanent Marker) to **signature accent
  only**: the "Nocturna" wordmark, section tags, and one hero accent. Never body/heading runs.
- **D-06:** Keep **Inter** for body (16px base, line-height 1.7) and **Space Mono** for meta/labels
  (eyebrows, prices with tabular figures, numbered steps), uppercase + wide tracking.

### Color / Surface
- **D-07:** Keep brand **red `#c0192c`** + **navy `#0a0c14`** but add **editorial section rhythm**:
  alternating **ink** (navy field, off-white text) and **paper** (`#f0eae4` field, near-black text)
  sections. Add semantic surface tokens (`--ink`, `--paper`, `--ink-on-paper`, `--paper-on-ink`).
- **D-08:** Use **red surgically** — one accent per section (a rule, a tag, a number, or the
  primary CTA). No splatter-everywhere. Red reserved for primary/destructive actions.

### Texture / Effects
- **D-09:** Refined (not brutalist) treatment: 0px radii, thin 1px rules/hairline borders, **giant
  Space Mono section numbers/tags** as editorial markers, headlines allowed to break lines
  graphically. Retain the **film-grain** overlay. Keep the restrained gallery **marquee** (Phase 2
  choreography), restyled.
- **D-10:** **Remove the custom cursor** (delete `src/scripts/motion/cursor.ts` +
  `src/styles/cursor.css` and their wiring). Hover/focus states become standard and accessible.
- **D-11:** Replace the busy hero (diagonal red/navy split + ink-splatter + heavy text-shadow) with
  a cleaner editorial hero. The Phase 2 WebGL shader canvas is retained only as a **decorative
  backdrop** that never gates type legibility.

### Structure / IA
- **D-12:** Reorder the landing to **visual-first**: Hero → **Featured gallery** → About + Process
  (6-step workflow as an editorial timeline) → Packages summary → Closing CTA. (Gallery rises above
  About.)
- **D-13:** Restyle `/servicios` (3 tiers Penumbra/Umbra/Eclipse, Umbra featured + add-ons +
  modular-catalog note), `/galeria` (masonry + lightbox + restyled empty state + category filter
  affordance), `/terminos` (paper reading column, 65–75ch, line-height 1.8), 404, and chrome to the
  system. "Abrir Ticket" reachable from every page.

### Claude's Discretion
- Exact type scale values, spacing rhythm, which sections are ink vs paper, the precise editorial
  grid, marquee speed, and the specific Tailwind `@theme` token naming — choose what best serves the
  look while honoring the decisions above.
- Whether to keep or retire the hero WebGL shader entirely if it fights the editorial hero (D-11
  allows decorative-only; dropping it is acceptable if cleaner).
</decisions>

<specifics>
## Specific Ideas

- Type pairing: Space Grotesk 700 (display) + A Another Tag/Permanent Marker (signature) + Inter
  (body) + Space Mono (labels) — per UI/UX Pro Max "Kinetic Brutalism (Space Grotesk)" pairing,
  tempered to refined-editorial.
- Quality bars (from UI/UX Pro Max, must hold): AA contrast ≥4.5:1 for text in BOTH ink and paper
  sections; touch targets ≥44px; visible focus rings; keyboard nav; `prefers-reduced-motion`
  respected; responsive at 375/768/1024/1440; no horizontal scroll; `min-h-dvh` over `100vh`;
  images AVIF/WebP, lazy below fold, reserved dimensions (CLS < 0.1); one primary CTA per screen;
  no emoji as structural icons (decorative ✦ accents OK).
</specifics>
