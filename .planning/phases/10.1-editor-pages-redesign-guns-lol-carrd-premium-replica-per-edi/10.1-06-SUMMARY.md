# Phase 10.1 Plan 06: Standalone EditorLayout shell + Splash + effects engine Summary

**The chrome-free `EditorLayout` every editor page mounts into: it emits a FIXED, numeric-clamped 12-token `--theme-*` whitelist from `editor.theme` (render-side theme-injection guard), preloads the one chosen curated font, renders the tiny nocturna watermark + themed background layer, mounts a click-to-enter `Splash` that dispatches the cross-plan `editor:enter` event exactly once, and drives an opt-in, reduced-motion-aware JS effects engine (typewriter/tilt/particles).**

## Performance

- **Duration:** ~15 min
- **Completed:** 2026-07-15
- **Tasks:** 3 (+1 cross-plan fix)
- **Files created:** 4 · **modified:** 1

## Accomplishments

- **EditorLayout.astro (Task 1):** a subtractive analog of BaseLayout — keeps only the doctype/head/lang skeleton and drops ALL site chrome (nav, footer, floating CTA, shared modal, view-transition router, brand stylesheets, hosted-fonts link, film grain, D-15). Imports only `editor-theme.css` + `editor-fonts.css`. Emits the FIXED 12-token `--theme-*` whitelist inline on the `.editor-page` root from `editor.theme`, each with a Midnight-Nocturna default; `overlay` clamped 0..100, `blur` clamped 0..20, `bgMedia` stripped + wrapped in `url()`, `font` resolved through a fixed family-name → slug map. Preloads ONLY the editor's one chosen woff2 (D-03). Renders the corner `nocturna` watermark (non-themed off-white 50%, links `/`), the themed `.editor-bg` layer, and sets `index,follow` + OG (name/tagline/avatar).
- **Splash.astro + splash.ts (Task 2):** a fixed full-viewport `role="dialog"` `aria-modal` gate with a blurred bg peek (`backdrop-filter`), the editor name (Display role, `--theme-font`), an Enter/Entrar CTA (`--theme-accent`), and a device-aware sub-label — copy in the editor's one language (D-13). `splash.ts` funnels click / Enter / Escape through a once-guard, fades the splash out, starts any `[data-editor-bg-video]`, and dispatches the document-level `editor:enter` CustomEvent EXACTLY ONCE (the unlock signal plan 04 consumes, D-22). Reduced-motion: instant hide, still dispatches.
- **effects.ts (Task 3):** reads active effects from the page-root `data-effects` attribute and wires only the JS effects — typewriter (char reveal + `aria-label` full text), tilt (`rotate3d`, fine-pointer devices only), and particles (a single capped-count 70-particle canvas, DPR ≤2, paused while the tab is hidden). The whole engine is gated behind `prefers-reduced-motion: reduce`; each effect no-ops when its key is absent. Hand-written, no animation library, no new npm dependency (T-10.1-06-SC).

## Deviations from Plan

### Auto-added / cross-plan

**1. [Rule 3 - Blocking cross-plan need] Declared `--type-*`/`--lh-*` primitives in the editor context**
- **Found during:** post-Task-2 coordinator message (contract update from plan 10.1-05)
- **Issue:** the re-themed editor-block components read `--type-*` (type scale) + `--lh-*` (line-height) custom properties, but the standalone editor context drops BaseLayout and never imports brand `theme.css`, so blocks would fall back to browser-default sizes.
- **Fix:** re-declared the 7 `--type-*` + 5 `--lh-*` keys verbatim from `theme.css` in `editor-theme.css` `:root`, alongside the already-carried `--space-*`/`--touch-min` primitives — no brand chrome imported.
- **Files modified:** `src/styles/editor-theme.css`
- **Commit:** `c13ff53`

**2. [Rule 2 - Missing critical functionality] Splash gained a `lang` prop**
- **Issue:** the plan's Splash props are `{ name }`, but the Copywriting Contract requires the Enter CTA + sub-label to render in the editor's ONE language (D-13). Without `lang` the copy could not be localized.
- **Fix:** added an optional `lang?: 'es' | 'en'` prop (default `es`); the layout passes `editor.lang`.
- **Files modified:** `src/components/editor-shell/Splash.astro`, `src/layouts/EditorLayout.astro`
- **Commit:** `0e1ea4f`
