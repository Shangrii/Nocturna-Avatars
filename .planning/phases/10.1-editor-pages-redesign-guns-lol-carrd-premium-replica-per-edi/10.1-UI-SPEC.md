# Phase 10.1 — UI Design Contract

> Visual and interaction contract for the editor-pages redesign (guns.lol/carrd premium replica). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **Scope note — read first.** This phase produces FOUR distinct surfaces with DIFFERENT contract rules:
> 1. **Public editor page** (`/e/<slug>`) — standalone, per-editor *free* theming (D-01/D-02/D-15). Colors/fonts are editor-chosen; the contract governs the SHELL STRUCTURE, the theme-token system, and the DEFAULT theme, not a fixed brand palette.
> 2. **Splash screen** (D-22) — themed per editor, fixed structure.
> 3. **`/editores` · `/editors` directory** (D-16) — unlisted, restyled to tease the new look; follows the Nocturna brand system.
> 4. **Admin theme-editor surface** (D-23) — side-by-side live preview panel in the Phase 10 admin app on cinema; follows the Nocturna brand system (dark, disciplined).
>
> Where the template asks for "the" color/typography contract, values are given for the **default theme** + **fixed chrome/admin** surfaces. Per-editor overrides are governed by the **Theme Token Contract** section below.

## Typography

The public editor page renders in **one editor-chosen font family** (D-03/D-13). The type ROLES below are **font-family-agnostic** — sizes, weights, and line-heights hold regardless of which curated font is selected. Fixed chrome/admin surfaces use the brand fonts.

| Role | Size | Weight | Line Height | Applies to |
|------|------|--------|-------------|------------|
| Display / Name | 32px (clamp 28–40) | 700 | 1.1 | Editor name in header card, splash name |
| Heading | 20px | 700 | 1.2 | Block section headings, badge-group labels |
| Body / Link label | 16px | 400 | 1.5 | Tagline, link-button labels, bio text |
| Micro | 12px | 400 | 1.4 | View count, watermark, badge captions, mono meta |

**Weights: exactly two — Regular 400 + Bold 700.** Name/headings/link-labels use 700; tagline/body/micro use 400.

**Curated-font weight fallback rule:** single-weight display faces (Press Start 2P, UnifrakturMaguntia, Pirata One, Bebas Neue) render at their native weight; hierarchy for those families is carried by SIZE and letter-spacing, not weight. The theme system must not request an unavailable weight (no synthetic bolding).

**Tagline animation (D-04, opt-in):** typewriter effect animates the tagline character reveal; static tagline is the reduced-motion and default fallback. Does not change type role.

| Role | Value | Usage |

| Dominant (60%) | `#0a0c14` (ink navy) | Page background behind glass card |

| Accent (10%) | `#c0192c` (brand red) | see reserved list |

**Accent reserved for (default theme):** avatar glow/ring, primary link-button fill + hover state, social-icon hover, view-counter icon, splash "enter" button, active/focus rings. Never applied to body text blocks or the whole card surface.

### Per-editor theming (D-01/D-02) — the contract is a TOKEN SYSTEM, not fixed values

Editor pages are **fully standalone** (D-15): no brand palette binding, no site chrome. Each editor sets colors via **free hex pickers** plus **professional palette presets**. The design contract the executor implements is the **theme-token schema** below — the page and every block read these CSS custom properties; there are no hard-coded colors in the editor-page shell or block components.

The 60/30/10 discipline is preserved *structurally* even under free theming: exactly one background field (`--theme-bg`/media), one card surface (`--theme-surface`), one accent (`--theme-accent`). Presets ship pre-balanced to this ratio; free pickers expose the same three roles so an editor cannot flood the page with accent.

### Fixed chrome / admin surfaces

| Surface | Palette |
|---------|---------|
| Directory `/editores`·`/editors` | Nocturna brand: ink `#0a0c14` bg, red `#c0192c` accent, off-white `#f0eae4` text (restyled to tease the new look — glass cards, editor-avatar tiles) |
| Admin theme-editor panel (cinema app) | Nocturna brand dark: ink bg, off-white text, red accent for active controls, `#e84a5e` for destructive |
| Nocturna watermark (D-15) | off-white `#f0eae4` at 50% opacity, links to main site; corner-pinned, non-themed |

**Contrast guarantee:** the background-treatment knobs (overlay 0–100%, blur, tint — D-21) exist to keep text legible over any media. The theme editor's live preview surfaces a contrast hint, but per D-02 free pickers are NOT hard-blocked. Default overlay for new pages: 40% darken, so text is legible before the editor tunes it.

## Theme Token Contract (per-editor override system — load-bearing for executor)

Every editor page is driven by CSS custom properties emitted from the `theme` object in `editors.json`. Block components (Phase 10 `src/components/editor-blocks/*`) must be refactored to read these tokens instead of brand tokens.

| Token | Type | Default | Feeds |
|-------|------|---------|-------|
| `--theme-bg` | color | `#0a0c14` | page background (behind media) |
| `--theme-bg-media` | url/none | none | image/gif/video layer |
| `--theme-overlay` | 0–100% | 40% | scrim darkness over media (D-21) |
| `--theme-blur` | 0–20px | 0 | media backdrop blur (D-21) |
| `--theme-tint` | color/none | none | media color tint (D-21) |
| `--theme-surface` | color/alpha | `rgba(240,234,228,0.06)` | glass card fill |
| `--theme-accent` | color | `#c0192c` | buttons, ring, icon hover, active |
| `--theme-text` | color | `#f0eae4` | body/link text |
| `--theme-text-muted` | color | `#9a9198` | tagline, meta |
| `--theme-font` | font family | `Inter` | one curated family (D-03) |
| `--theme-btn-style` | filled\|outline\|glass | glass | link-button treatment (D-11) |
| `--theme-btn-shape` | sharp\|rounded\|pill | rounded | corner radius (D-11: 0 / 12px / 999px) |

**Button variants (D-11) — style × shape matrix, no per-button overrides:** all link buttons on a page share one style + one shape; accent + hover come from the theme. Hover animation is one editor-chosen effect (see Effects Catalog).

## Effects Catalog (D-04 — full premium suite, all opt-in per editor)

Each effect is an independent per-editor toggle. Executor must implement each with a reduced-motion fallback.

| Effect | Technique (discretion, resolved) | Reduced-motion fallback |
|--------|----------------------------------|-------------------------|
| Glassmorphism cards | `backdrop-filter: blur()` + alpha surface | static translucent card (no blur if unsupported) |
| Avatar glow / ring | accent box-shadow + conic ring | static ring, no pulse |
| Link-button hover anim | transform/scale/sheen on hover | color change only |
| Animated username gradient | CSS `background-clip:text` + keyframes | static gradient |
| Typewriter tagline | JS char reveal | full static tagline |
| Tilt-on-hover | pointer-driven `rotate3d` (JS, pointer-only) | disabled |
| Particle / snow overlay | lightweight canvas layer, capped particle count | disabled (no canvas) |
| Background overlay controls | `--theme-overlay`/`--theme-blur`/`--theme-tint` | always active (legibility, not motion) |
| Live Discord presence | Lanyard client fetch (D-05) | hidden if unreachable |
| Background audio | click-to-enter unlock + volume slider (D-06) | muted default; splash gates it |

**Global reduced-motion:** `@media (prefers-reduced-motion: reduce)` disables all motion effects (typewriter, tilt, particles, gradient anim, hover transforms, background video pauses to poster frame). Overlay/blur/tint stay on. Consistent with the site-wide reduced-motion discipline established in Phase 2.

**Performance budget:** at most ONE canvas effect (particles) active per page; background video ≤10MB (D-19), decoded after splash dismiss (D-22) so first paint is the poster frame.

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Page load | Splash shows first (blurred bg peek + name + enter). Background video/audio DO NOT play until enter is pressed (autoplay + audio unlock, D-22). |
| Splash dismiss | Fade out; background media begins; audio starts muted-or-playing per editor setting with volume control visible; view-counter ping fires once. |
| Old-route hit (`/es/editores/<slug>`, `/en/editors/<slug>`) | Redirect to `/e/<slug>` — static-host mechanism: build-time canonical stub pages with `<meta http-equiv="refresh">` + `<link rel="canonical">` + JS replace (D-14). |
| Store/gallery editor credit click (D-17) | Navigates to `/e/<slug>` via the single `editorPath()` helper (`routes.ts`). |
| Portfolio thumbnail tap (D-12) | Opens lightbox in place (reuse gallery lightbox pattern). |
| Social icon tap | Opens platform URL in new tab (`rel="noopener"`). |
| Reduced motion | All motion effects disabled; overlay/blur/tint retained; video → poster frame. |
| Mobile (D-20) | Same experience: muted looping video autoplays post-splash; 44px touch targets. |

**Discovery/SEO (discretion, resolved):** editor pages are `index,follow` (organic discovery is the goal — D-17); include per-page `<title>`/OG from name+tagline+avatar. Directory is `noindex,follow` (unlisted but crawlable via links — D-16). Emit both into the sitemap under `/e/<slug>`.
