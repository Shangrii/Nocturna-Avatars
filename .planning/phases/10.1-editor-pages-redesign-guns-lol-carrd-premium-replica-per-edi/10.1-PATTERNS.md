**getStaticPaths defensive read (analog L36-56):**
```typescript
export function getStaticPaths() {
  const raw: Editor[] = Array.isArray(editorsData) ? ([...editorsData] as Editor[]) : [];
  const published = raw.filter(
    (e) => Boolean(e) && e.published === true && typeof e.slug === 'string' && e.slug.length > 0,
  );
  return published.map((editor) => ({ params: { slug: editor.slug }, props: { editor } }));
  // ↑ D-13: drop `langCodes.map(...)` cartesian — ONE page per editor now.
}
```

## Shared Patterns

### Theme Token System (load-bearing — applies to EditorLayout + ALL editor-shell + editor-blocks)
**Source pattern:** `src/styles/theme.css` `@theme` block (L14-116) — how the project defines CSS custom properties that component CSS reads via `var(--…)`.
**Apply as:** the editor page does NOT import brand `theme.css`. Instead `EditorLayout` emits the 13 `--theme-*` properties (Theme Token Contract table) as an inline `style` on the page root, sourced from `editor.theme`. Every editor-shell + block component reads `var(--theme-accent)` / `var(--theme-surface)` / `var(--theme-font)` etc. — never `var(--color-red)`. Defaults = Midnight Nocturna (D-26). Spacing (`--space-*`) and `--touch-min` DO carry over from `theme.css` (UI-SPEC adopts the existing scale).

### Defensive external-data read (applies to `e/[slug].astro`, all blocks, directory)
**Source:** `[slug].astro` L36-77, `PortfolioBlock.astro` L61-119, `EditorsDirectory.astro` L46-63.
**Pattern:** copy-before-filter (`[...editorsData]`), per-entry `Boolean(e) && typeof e.slug === 'string'` guards, per-field `?? fallback`. One malformed entry is skipped, never thrown — `editors.json` is a bot write target; a bad row must never freeze the deploy (T-10-07-02).

### XSS discipline (applies to every component rendering editor data)
**Source:** `BlockRenderer.astro` L1-13, `LinksBlock.astro` L9-11, `gallery.ts` L604.
**Pattern:** all editor/Discord-sourced content renders through Astro `{}` auto-escaping (Astro components) or `textContent` (client JS) ONLY — never `set:html`/`innerHTML` (D-02). Preserve while restyling.

### Untrusted outbound links (LinkButton, SocialIconRow, header links)
**Source:** `LinksBlock.astro` L29-39.
**Pattern:** `target="_blank" rel="noopener noreferrer nofollow"` on every editor-supplied URL (T-10-04-02).

### Reduced-motion (all effects, splash, buttons)
**Source:** `LinksBlock.astro` L76-80, `BaseLayout.astro` glitch-wipe note L36, project-wide Phase 2 discipline.
**Pattern:** `@media (prefers-reduced-motion: reduce)` disables every motion effect (typewriter, tilt, particles, gradient anim, hover transforms, bg video→poster); overlay/blur/tint stay on (UI-SPEC Effects Catalog Global reduced-motion).

### Lightbox reuse (PortfolioBlock)
**Source:** `src/components/LightboxOverlay.astro` (whole) + `src/scripts/gallery.ts` (L628-691, entries derived from `[data-gallery-tile]`).
**Pattern:** render one `[data-lightbox-overlay]` per page + tag portfolio cells `[data-gallery-tile]`; the existing `gallery.ts` binding wires open/prev/next with zero new JS.

### Static-host client redirect (old-route stubs)
**Source:** `src/pages/index.astro` L24-48.
**Pattern:** `<meta http-equiv="refresh">` + `<noscript>` fallback + `is:inline` `location.replace(LITERAL)` + `noindex`. Target is a build-time literal (T-01-03 — no runtime interpolation).

### Cinema (nocturna-bot) endpoint + deploy (admin theme panel, media/audio upload, view counter)
**Source:** Phase 10 `10-10`/`10-11` summaries — `../nocturna-bot/app/main.py` (FastAPI, `require_editor` IDOR choke-point, session identity forced LAST over body — D-08), `app/templates/editor.html` (two-pane Alpine `x-data`/`x-for` live preview + SortableJS), `app/static/editor.css` (brand-token CSS), `POST /editor/image` (SVG-reject by content-type AND extension, streamed size-cap early abort, Pillow re-encode to WebP, commit only re-encoded bytes via `sync_editors`), `deploy/nocturna-editor-admin.service` + `Caddyfile.snippet` (sibling systemd/uvicorn loopback:8770 behind Caddy auto-HTTPS + proxy rate-limit).
