## Decisions Made

- **SPECIALTY_BADGES key set locked** to `{Outfits, Accessories, Dances, Textures, Blender, Modeling3D}`, derived from the site's own service categories (`home.json`/`services.json`) since UI-SPEC gave only an illustrative `Outfits/Texturas/Blender/Dances…` list. Keys are language-agnostic; the front-end `SpecialtyBadges.astro` maps each to a localized label + glyph.
- **KNOWN_EFFECTS** = the 9 opt-in Effects-Catalog toggle keys. Background overlay/blur/tint are always-on legibility controls (their own numeric fields), not toggle effects, so they are not effect keys.
- **Color regexes use `fullmatch` without `^$` anchors** so an embedded newline/`;` cannot smuggle a second CSS declaration; `surface`/`tint` additionally accept a strict numeric `rgb()/rgba()` (alpha needed for the glass fill), while `bg`/`accent`/`text`/`textMuted` are hex-only.
- **out-of-range overlay/blur → reject** (pydantic `ge/le`), not silent clamp — a malformed value is surfaced as input feedback.
