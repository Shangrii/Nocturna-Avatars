<objective>
Extend the bot-side pydantic gate (`core/editors_model.py`) — the server-side validation every editor save passes through before a commit — with a `ThemeModel` and the new `EditorPage` fields (lang, single-string tagline, badges, socials, theme). This is the LOAD-BEARING theme-injection mitigation: colors must be hex, button style/shape must be enums, overlay/blur numeric-in-range, font one of the 14 curated keys, effects from the known set, and media/audio refs pass the existing `is_safe_image_ref`/scheme guard — so a crafted theme value can never smuggle a dangerous string into the CSS custom properties or `<img/video/audio src>` the website emits.

Purpose: The website render layer trusts NOTHING, but this schema is where editor-controlled theme values are constrained at the source. Cross-repo, bot-side; TDD.
Output: `core/editors_model.py` (ThemeModel + extended EditorPage), `tests/test_editors_model.py`.
