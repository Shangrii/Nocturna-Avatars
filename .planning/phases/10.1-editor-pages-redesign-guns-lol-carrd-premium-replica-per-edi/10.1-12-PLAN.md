## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → counter endpoint | Unauthenticated public GET that mutates a counter. |
| client IP → dedup store | Client IP used for dedup; a privacy concern if stored raw. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10.1-12-01 | DoS / count inflation | GET /api/views increment | mitigate | Proxy-level Caddy `rate_limit` per IP + app-level per-slug+ip_hash dedup window; a reload/bot loop can't inflate unboundedly. |
| T-10.1-12-02 | Info disclosure (privacy) | dedup IP storage | mitigate | Only a HASH of the client IP is stored, never the raw address; short retention window. |
| T-10.1-12-03 | Injection | slug path segment → SQL | mitigate | Slug validated `[a-z0-9-]+` before use AND all DB access uses `?`-placeholders (no string interpolation into SQL). |
| T-10.1-12-04 | CSRF/abuse | cross-origin increment | accept | The endpoint is intentionally public (a view counter); CORS scopes browser reads to the site origin, but the increment is low-value and rate-limited — no auth needed (D-25 "tiny counter"). |
| T-10.1-12-SC | Supply chain | deps | mitigate | Reuses already-pinned FastAPI/uvicorn (10-02); no new pip package. Deploy artifacts contain no secrets. |
