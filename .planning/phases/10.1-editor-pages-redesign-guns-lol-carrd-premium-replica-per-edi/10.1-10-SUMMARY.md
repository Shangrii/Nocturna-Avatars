## Accomplishments
- Extended `editorApp(...)` state with a `page.theme` object (Midnight-Nocturna defaults matching plan-09's ThemeModel), `page.lang`, `page.badges`, and `page.socials`; migrated the tagline to a single-language field (D-13) with legacy `{es,en}` back-compat.
- Added six grouped theme control sections: Background (media upload + overlay/blur ranges + tint), Colors (free hex pickers + surface), Typography (14 curated fonts), Buttons (style × shape enums), Effects (9 KNOWN_EFFECTS toggles), Audio (upload + clear).
- Added a curated specialty-badge multi-select (SPECIALTY_BADGES, no free text) and an https socials repeater mirroring the links-block editor.
- Bound the `.preview-col` root inline style to emit every `--theme-*` token; preview CSS now consumes them so name/tagline/links/badges reflect theme changes instantly (D-23) — all preview text via `x-text` only (no `x-html`, D-02).
- Added 8 one-click presets (Midnight Nocturna, Neon Night, Soft Pastel, Gothic, Y2K, Vaporwave, Minimal Mono, Sakura); `applyPreset()` overwrites palette+font+buttons+effects then leaves every knob editable (apply-then-tweak, D-24) — local state only, no fetch/commit.
- Added a reset-theme inline confirm with the exact UI-SPEC ES/EN copy, resetting to Midnight defaults; neither preset-apply nor reset commits until the existing Save.
