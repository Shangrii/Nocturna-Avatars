<objective>
Extend the proven cross-repo transport with an OBJECT-aware `store.json` path: read/write the `{_comment, products}` object (preserving `_comment`), commit the merged products list only when something changed, and commit staff-attached images + description in one atomic commit — reusing the retry core, lock, and typed errors unchanged.

Purpose: This is the third genuinely-new mechanic (RESEARCH Pattern 2 / Pitfall 1 — the load-bearing divergence). The generic `_fetch_json` explicitly raises on a non-array body, so `store.json` (an object) cannot reuse it. A naive rewrite would drop the `_comment` schema doc staff rely on. Everything else (blob→tree→commit→ref, `_commit_lock`, `_commit_with_retry(fetch=...)`, backoff) is reused verbatim.
Output: object-aware `_fetch_store`, `sync_store`, and `attach_store_media` in `core/github_publish.py` + `tests/test_store_publish.py`. Gallery + reviews transports remain byte-for-byte unchanged.
</objective>
