Canonical editors.json entry schema (this plan LOCKS it; all other plans mirror it verbatim):
- slug: string, charset [a-z0-9-], unique, URL label only
- discordId: string snowflake — the TRUE 1:1 key (D-08); never a writable field from a request body
- published: boolean
- name: string (single language display name)
- avatar: string path under /editors/<slug>/ or "" when unset
- tagline: { es: string, en: string }
- links: array of { label: string, url: string (https:// only, D-16) }
- blocks: ordered array; each block is one of the closed union (D-02, UI-SPEC Block Inventory):
    { type: "bio",     text: {es,en} }
    { type: "heading", text: {es,en} }
    { type: "text",    text: {es,en} }
    { type: "links",   items: [{label,url}] }
    { type: "portfolio", auto: boolean, extra: [{image, caption:{es,en}}] }
    { type: "quote",   text: {es,en}, attribution?: string }
    { type: "image",   src: string, alt: string }
    { type: "divider" }

gallery.json gains TWO new OPTIONAL fields this phase: `editor: string` (slug, D-11) and `nsfw: boolean` (D-04 — present-and-true ONLY for NSFW photos; a missing field means SFW, so all historical entries stay valid).
