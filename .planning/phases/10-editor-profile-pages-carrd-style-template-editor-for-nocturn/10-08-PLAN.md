<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → OAuth login | Untrusted visitors authenticate; only editor-role holders get a session |
| session → editable identity | The editable page is bound to the session's discordId, never request input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-08-01 | Spoofing | OAuth callback CSRF | mitigate | Authlib-generated `state` bound to session, verified on callback (Pitfall 4) |
| T-10-08-02 | Elevation/Tampering | IDOR edit another page | mitigate | `require_editor` resolves identity from session only; body slug/discordId ignored (D-08 / Pitfall 1) |
| T-10-08-03 | Elevation | stale session after role loss | mitigate | Re-check role on every `require_editor` call + short TTL; on_member_update unpublish in 10-10 (Pitfall 2) |
| T-10-08-04 | Spoofing | open redirect post-login | mitigate | Fixed internal redirect target; registered redirect URI only (Pitfall 4) |
| T-10-08-05 | Info Disclosure | bot token / client secret / OAuth code | mitigate | Server-side only; never logged; role read uses Bot token, never client-exposed |
| T-10-08-06 | Elevation | non-editor obtaining a session | mitigate | Session issued only after the bot-token role check passes (D-07/D-15) |
</threat_model>
