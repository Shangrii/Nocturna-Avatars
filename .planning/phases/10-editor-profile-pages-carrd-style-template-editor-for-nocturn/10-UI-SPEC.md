# Phase 10 — UI Design Contract

> Visual and interaction contract for the Editor Profile Pages phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This phase has TWO distinct UI surfaces:**
> - **Surface A — Public editor pages + directory** (website repo, static Astro). MUST reuse the existing "Refined Street Editorial" design system verbatim (`src/styles/theme.css`). No new visual language.
> - **Surface B — Editor admin app** (nocturna-bot repo, FastAPI + Jinja2 + Alpine.js + SortableJS). A new internal, editor-only tool. Brand-adjacent but functional; it is NOT deployed to the public site (D-06).
>
> The design tokens below are the SINGLE source of truth for both surfaces; Surface B echoes the same palette/type but is chrome-light (a builder tool, not a marketing page).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (project deliberately excludes React/shadcn — Phase 2.1 decision "no React/shadcn is added") |
| Preset | not applicable |
| Component library | none — hand-authored Astro components (Surface A) + Jinja2 partials (Surface B) |
| Icon library | none installed; use inline SVG or Unicode/emoji glyphs consistent with existing chrome (🌙 ✅ etc.). Do NOT add an icon package. |
| Font | Space Grotesk (display/heading), Inter (body), Space Mono (labels/mono), "A Another Tag" → Permanent Marker (graffiti accent, wordmark/section-tag only) |

**shadcn gate:** `components.json` NOT found. Tech stack is Astro static output + a Python/Jinja2/Alpine admin app — neither is a React/Next/Vite target, and the project explicitly forbids adding React/shadcn. shadcn is therefore **not applicable**. Registry safety gate: not applicable.

**Token source of truth:** `src/styles/theme.css` (`@theme` block). Surface A consumes these as Tailwind utilities (`bg-ink`, `text-red`, `font-display`, …) and CSS vars. Surface B vendors an equivalent CSS variable sheet (same hex values) — do not fork the palette.

## Spacing Scale

Declared values (existing 8-point scale from `theme.css`, all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| 3xs | 4px | Icon gaps, inline padding, tag insets |
| 2xs | 8px | Compact element spacing (link-button padding) |
| xs | 12px | Form-field internal padding, chip gaps |
| sm | 16px | Default element spacing, block internal padding |
| md | 24px | Between blocks in the editor preview / profile column |
| lg | 32px | Card padding, directory grid gap |
| xl | 48px | Major section breaks |
| 2xl | 64px | Page-level spacing |
| section | `clamp(60px, 10vw, 120px)` | Public page top/bottom padding (matches `--section-pad`) |

**Exceptions:**
- Minimum touch target 44px (`--touch-min`) for all admin-app controls (add/remove/reorder handles, upload, save) and public link-buttons — PLAT-04 / a11y.
- Public profile column max-width ~640px (carrd/guns.lol single-column feel); directory grid uses `--page-gutter` `clamp(20px, 4vw, 48px)` as the page gutter.

## Typography

Roles (exactly 4 sizes, exactly 2 weights — matches the disciplined Phase 2.1 system):

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Display | `clamp(46px, 11.5vw, 240px)` | 700 | 0.9 | A Another Tag (wordmark only) / Space Grotesk 700 (editor name) |
| Heading | `clamp(24px, 5vw, 44px)` | 700 | 1.15 | Space Grotesk |
| Body | 16px | 400 | 1.7 | Inter |
| Label | `clamp(10px, 1.4vw, 12px)` | 400 | 1.4 | Space Mono (uppercase, letter-spaced — eyebrows, block-type tags, credited badge) |

**Weights:** exactly two — **400 (regular)** for body + mono labels, **700 (bold)** for display + headings. No other weights.

Card/quote title uses `--type-card-title` `clamp(20px, 3vw, 28px)` at 700 (a size variant of Heading, not a new role).

## Color

Editorial ink/paper rhythm (existing brand system). 60/30/10 split:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0a0c14` (ink navy) | Base page field, profile background, admin app background |
| Secondary (30%) | `#10131e` (ink-raised) / `#11141f` (warm paper) | Cards, block surfaces, directory tiles, admin panels, alternating warm/cool section rhythm |
| Accent (10%) | `#c0192c` (brand red) | See reserved list below |
| Destructive | `#c0192c` (brand red) + explicit confirm | Unpublish / delete-block / remove-image — no separate destructive hue exists; distinguish by confirmation UX, not color |

**AA-safe red variants (do not substitute):** small red text on ink uses `#e84a5e` (`--color-red-on-ink`); on paper uses `#c0192c` (`--color-red-on-paper`); the large editor-name/wordmark may use `#cd2236` (`--color-red-wordmark`). Foreground off-white is `#f0eae4`; dim `#9a9198`.

**Accent reserved for (explicit list — never "all interactive elements"):**
- Section eyebrows / block-type tags / the "credited work" portfolio badge (Space Mono labels)
- The editor's name accent on the profile header
- Primary CTA fills — the site-wide "Abrir Ticket" button on public pages; the **Save / Publish** button in the admin app
- Hairline rules / dividers (the `divider` block, section rules)
- Link hover underline / active nav indicator
- Focus ring on admin form fields and the active/being-dragged block outline

Everything else (link-buttons, block cards, directory tiles, form inputs) stays ink/paper + off-white; red is a surgical accent only.

## Block Inventory (v1 — resolves D-02 / Claude's discretion A7)

Fixed, closed set of typed blocks. Each renders via a dedicated Astro component (Surface A) and a matching Jinja2/Alpine preview partial (Surface B). No raw HTML/CSS — Astro auto-escaping only (security V5).

| Block | Fields | Notes |
|-------|--------|-------|
| `bio` | `text {es,en}` | Paragraph. Part of/adjacent to the header (name+avatar+tagline are core fields, not blocks — D-01). |
| `heading` | `text {es,en}` | Section heading (Heading role). |
| `text` | `text {es,en}` | Plain paragraph (Body role). |
| `links` | `items[] { label, url }` | Stacked full-width link-buttons (guns.lol style). URL: `https://` only (D-16), no allowlist. |
| `portfolio` | `auto: bool`, `extra[] { image, caption {es,en} }` | Auto-pulls SFW credited work by exact slug from `store.json` + `gallery.json` (D-03/D-04/D-12); appends hand-added items. Grid of image cards. |
| `quote` | `text {es,en}`, `attribution?` | Pull-quote (Space Grotesk 700, red rule accent). |
| `image` | `src`, `alt` | Single optimized WebP image, full column width. |
| `divider` | — | Hairline red/border rule. |

**Deferred to v2 (locked here per A6 / D-02 "if scope allows"):** per-block brand-constrained color/background options. v1 blocks render in the default ink/paper + red-accent system only. Do NOT build a per-block color picker in v1.

## Layout Contract

**Surface A — Public profile page** (`/en/editors/<slug>` · `/es/editores/<slug>`):
- Single centered column, max-width ~640px, ink background, section padding top/bottom.
- Header: avatar (circular, ~120–160px), editor name (Display/Heading, red-accent), tagline (Body dim), custom links row/stack.
- Blocks render in editor-defined order, `md` (24px) vertical rhythm between blocks.
- The site chrome (Nav, Footer, FloatingCTA, LanguageSwitcher, NightBackground) wraps the page — "Abrir Ticket" reachable (NAV-03).

**Surface A — Directory** (`/en/editors` · `/es/editores`):
- Heading + subhead, then a responsive grid of editor cards (avatar + name + tagline), each linking to the profile. Grid: 1 col mobile → 2–3 col desktop, `lg` (32px) gap. Only `published` editors listed.

**Surface B — Admin block editor:**
- Two-pane on desktop (≥1024px): left = block list/editor (add / drag-reorder via SortableJS / per-block fields / remove), right = **live preview** (D-14, Alpine.js reactive) rendered in the profile's actual look.
- Single-pane stacked on mobile (edit panel; preview via a toggle/tab).
- Persistent top bar: page title + **Publish** (accent), **Unpublish** (red, destructive), sign-out.
- Image-upload widget shows an "optimizing…" state while Pillow re-encodes server-side.

## Interaction Contracts

| Interaction | Contract |
|-------------|----------|
| Reorder blocks | Drag handle (SortableJS) — MUST also be keyboard-operable (move up/down buttons or ARIA); 44px targets. |
| Add block | "Add block" opens a typed picker (the closed block set above); appends to the list. |
| Remove block | Explicit confirm (copy above); animates out. |
| Live preview | Updates on every field change (Alpine `x-model`) — the preview approximates the Astro render; the authoritative output is only the static build (documented fidelity gap). |
| Bilingual fields | Per-locale `{es,en}` inputs (tabbed or paired) for bio/quote/tagline/heading/text/captions. Empty locale is allowed (rendered as written, per site convention). |
| Image upload | File picker → client size check → server: reject SVG, size-cap, Pillow decode + re-encode to WebP. Progress/optimizing state; error copy above. |
| Save/Publish | Single action; publishes immediately (D-13). Success toast + "couple of minutes" note; disabled/spinner while committing. |
| Login | Discord OAuth2 → guild role check → session. Non-editors see the 403 copy, never the editor UI. |

**A11y / responsive (both surfaces):** AA contrast in ink and paper fields; `prefers-reduced-motion` respected (no essential motion); keyboard-navigable (esp. block reorder); responsive at 375 / 768 / 1024 / 1440; 44px minimum touch targets. Consistent with the Refined Street Editorial quality bar.
