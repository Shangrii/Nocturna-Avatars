# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1 (Foundation & Bilingual Shell). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** This phase ships the *structural / brand shell* only. Motion, WebGL hero, scroll reveals, view transitions, and cursor effects are **Phase 2** — do NOT implement them here, but keep markup animation-ready (neutral `reveal` hooks, no inline transforms that would fight GSAP later). The `/galeria` and `/servicios` pages are **shells** in this phase (real data-driven rendering lands in Phases 3 and 4).
>
> The visual identity is **already locked** (carried from `styles.css` `:root` + `index.html`). This contract formalizes those tokens; it does not reinvent the brand.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Astro static site; brand already defined as CSS custom properties — no shadcn/component registry) |
| Preset | not applicable |
| Component library | none (hand-authored Astro components from existing CSS) — registry safety gate not applicable |
| Icon library | inline SVG / existing glyphs (`✦`, scroll chevron, Discord mark). No icon-font dependency. New nav/lang icons as inline SVG. |
| Fonts | **Display/graffiti:** `A Another Tag` (custom `@font-face`, `assets/fonts/a-another-tag.{woff2,woff,ttf}`). **Display secondary:** `Permanent Marker`. **Body:** `Inter`. **Mono/labels:** `Space Mono`. Google Fonts `<link>` for the latter three in the base layout `<head>`. |
| Texture | Film-grain SVG noise overlay via `body::after` (carry over verbatim, `opacity: 0.45`, `z-index: 9999`, `pointer-events: none`). Global layer on every page. |

**Token source of truth:** the `:root` block in `styles.css` becomes the centralized design-system custom properties (PLAT-03). Every component reads from these tokens — no hard-coded hex/px in components.

**`A Another Tag` rule (locked):** this face renders visually small at a given px and is reserved for **display + accents only** (brand wordmark, hero title, oversized section accents, tag/sticker labels) — **never body, never paragraphs, never UI labels**. Bump its rendered scale ~1.15–1.3× relative to where you'd size `Permanent Marker` for the same role so optical weight matches. Body stays `Inter`.

## Spacing Scale

8-point scale (multiples of 4). Carried/normalized from the existing CSS, which already clusters on 4/8/12/16/24/32/40.

| Token | Value | Usage |
|-------|-------|-------|
| 3xs | 4px | Hairline gaps, icon insets, mono-label letter rhythm |
| 2xs | 8px | Compact element spacing, nav-link vertical padding |
| xs | 12px | Chip/pill padding, tight stacks |
| sm | 16px | Default element spacing, card inner gap |
| md | 24px | Card padding, sub-group gaps |
| lg | 32px | Card padding (generous), inline section gutters |
| xl | 48px | Page side gutters (max), header→content gap |
| 2xl | 64px | Nav height (`--nav-h: 64px`); major in-section breaks |
| 3xl | clamp(60px, 10vw, 120px) | `--section-pad` — vertical rhythm between landing sections (carry existing value) |

**Exceptions:**
- **Touch targets:** interactive controls (nav links, lang switcher, hamburger, floating CTA) must have a **minimum 44×44px** hit area on mobile even when the visual chip is smaller — pad to reach it. This is the only sanctioned non-8pt value and exists for accessibility (PLAT-04).
- **Page side gutter** is fluid: `clamp(20px, 4vw, 48px)` (carry existing nav padding convention) — endpoints (20/48) are on-scale.
- **Hero letter-spacing** (`12px` on the brand title) is a display typographic value, not layout spacing — out of scope for the spacing scale.

## Typography

Type scale formalized from the existing CSS. **Exactly 4 roles** below are the contract; the listed sub-uses inherit from their role. Sizes use `clamp()` for fluid responsiveness (PLAT-04).

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 16px (paragraphs); 15px (dense secondary text) | 400 | 1.7 | Inter |
| Label | 10–12px, `text-transform: uppercase`, `letter-spacing: 0.15–0.3em` | 400 | 1.4 | Space Mono |
| Heading | `clamp(24px, 5vw, 44px)` (section titles); 20–28px (card titles) | 400 | 1.15 | Permanent Marker |
| Display | `clamp(56px, 14vw, 300px)` (hero brand); 33px (nav wordmark); large accents | normal | 0.9 | A Another Tag |

**Weights — exactly 2 declared:** `Inter` ships at **400 (regular)** and **300 (light)**. Body copy is 400; large hero taglines / lead subtitles may use 300 for an airy display feel (carried from existing `.hero-tagline` / `.section-subtitle`). Display/graffiti fonts have a single weight each (`normal`) and are not part of the 2-weight body count.

**Line-height rules:**
- Body / paragraphs: **1.7** (carry existing — generous, suits the dark editorial feel).
- Terms / long-form legal blocks: **1.8** for readability.
- Headings (`Permanent Marker`): **1.15**.
- Display (`A Another Tag`): **0.9** (tight, poster-like).
- Mono labels: **1.4**.

**Hierarchy intent:** mono uppercase labels (eyebrows, section tags, prices-in-mono) sit *above* headings as kicker text; `Permanent Marker` carries section/card titles; `A Another Tag` is the brand/hero spectacle only.

## Color

60/30/10 split mapped onto the locked palette. All values are existing `:root` tokens.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--navy: #0a0c14` | Page background, the void behind every section |
| Secondary (30%) | `--navy-mid: #10131e`, `--navy-light: #181c2e`, `--navy-surface: #141828` | Cards, package tiers, nav scrolled bg, footer, modals, elevated surfaces. Borders: `--border: rgba(255,255,255,0.06)`; tape/divider fills: `--white-muted: rgba(240,234,228,0.06)` |
| Accent (10%) | `--red: #c0192c` (base), `--red-dark: #7a0f1a` (hover/pressed), `--red-glow: #e8223b` (glows/emphasis), `--red-soft: rgba(192,25,44,0.12)` (tinted backgrounds) | See reserved-for list below |
| Foreground | `--white: #f0eae4` (primary text), `--white-dim: #9a9198` (secondary/muted text, inactive nav) | Text — not part of the 60/30/10 surface budget |
| Destructive | `--red: #c0192c` (reuses accent red) | No destructive *data* actions exist in Phase 1; see Copywriting Contract. If a confirm is needed, it shares the accent red — no separate semantic color is introduced this phase. |

**Accent (red) reserved for — explicit list (never "all interactive elements"):**
1. The **brand wordmark** ("NOCTURNA") and active-nav indicator.
2. The **primary CTA** ("Abrir Ticket" / Discord button) — nav CTA, hero outline CTA, card CTAs, and the persistent floating CTA.
3. The **active language** state in the language switcher.
4. **Glow / spray accent** decoration on the hero and section dividers (subtle, low-opacity `--red-glow`).
5. The **featured/recommended package tier** highlight border on `/servicios` (single tier only).

Everything else — body text, default nav links, card chrome, borders, dividers — stays in the navy/off-white range. Red must remain ≤ ~10% of any viewport so the CTA reads as *the* action.

**Contrast (PLAT-04 / a11y):** `--white #f0eae4` on `--navy #0a0c14` and on `--navy-surface #141828` passes AA for body. `--white-dim #9a9198` is for ≥14px secondary text only (do not use for body paragraphs or for text below 12px). The red CTA uses `--white` foreground (passes AA on `--red`).

## Component & Layout Contract (phase-specific)

> Phase-1 deliverable is a set of shared, reusable Astro components + page layouts. This section is the inventory the planner/executor build against. Tokens above govern all of them.

### Global chrome (every page)

**Nav (`NAV-01`-adjacent, NAV-03):** fixed top, `height: --nav-h (64px)`, transparent at top → `rgba(10,12,20,0.92)` + `blur(14px)` + bottom border when scrolled (`.scrolled`). Contents left→right:
- Brand wordmark `NOCTURNA` (`A Another Tag`, red, links to localized `/`).
- Nav links (Space Mono, 10px uppercase, `--white-dim` default → `--white` hover → `--red` active with underline). Items link to **pages**, not anchors (multi-page model, D / canonical): localized `/`, `/servicios`, `/galeria`, `/terminos`.
- **Language switcher** (see below).
- Primary CTA `Discord` / `Abrir Ticket` (red pill).
- Mobile: hamburger `.nav-toggle` toggles a drawer; all controls ≥44px touch target.

**Language switcher (I18N-01, D-06):** compact `ES | EN` toggle (Space Mono labels). Active language in `--red`, inactive in `--white-dim`. **Preserves the current page** when switching (`/es/servicios` ↔ `/en/servicios`, never resets to home). Honors stored preference (D-05); does not override a manual pick. Min 44px touch target per option.

**Persistent floating CTA (NAV-03):** a stylized floating "Abrir Ticket" control fixed to a corner (bottom-right recommended), present on **every page including the shells and 404**. Opens the Discord modal (or links to `discord.gg/DSMmwU35cs`). Red accent, animation-ready (no required animation this phase). Must not obscure footer links or the nav CTA.

**Discord modal (shared component):** overlay + centered modal with red glow, title, body, primary `Abrir Discord` link (`https://discord.gg/DSMmwU35cs`, `target="_blank" rel="noopener"`), and dismiss. Re-implements the existing `.dc-trigger`/`.dc-overlay` pattern as one shared component (any `dc-trigger` opens it).

**Footer (every page):** navy surface, brand, nav links, Discord link, copyright. Carry existing footer structure/styling.

**Film-grain overlay + scroll behaviors:** grain is global. `scroll-behavior: smooth` stays as a CSS baseline; the Lenis/GSAP motion layer is Phase 2 — keep `reveal` class hooks present but inert.

### Landing composition (`/`, NAV-01) — re-composed curated summary (D-10)

Section order (top → bottom). The landing is a *curated teaser* that links out to dedicated pages — not the old 1:1 single-page dump.

1. **Hero** — eyebrow (mono) → brand title (`A Another Tag`, oversized) → twin taglines with `✦` divider → service keyword row (Ropa · Accesorios · Bailes · Modelado 3D · Texturas) → dual CTA (`Ver Paquetes` + `Abrir Ticket`) → scroll cue. WebGL shader is a Phase-2 layer; ship a static hero background (grid + red glow) now, structured so the shader can mount over it later.
2. **About / "Quiénes somos"** — section tag + title ("No somos 'comisiones por mensaje'.") + subtitle, the about feature row, and the process/workflow steps (carry existing copy, polished).
3. **Featured work placeholder** (NAV-01 "featured work") — a small curated teaser grid pointing to `/galeria`. In Phase 1 this is a **placeholder** (the real featured subset is Phase 4); use the empty/coming-soon state with a `Ver galería` link.
4. **Packages summary** — the 3 tiers condensed (name + price + one-line + `Abrir Ticket`), with a `Ver todos los servicios` link to `/servicios`. Hard data faithful: **Penumbra $40 / Umbra $60 / Eclipse $90 USD** (D-12).
5. **Gallery teaser** — visual strip linking to `/galeria` (placeholder state in Phase 1).
6. **About story / closing** — "Nuestra historia" closing block + final conversion nudge.
7. **Footer** (global).

### Dedicated page shells

| Route (localized) | Phase-1 deliverable | Notes |
|-------------------|--------------------|-------|
| `/{lang}/servicios` | Real 3-package section (data faithful) + **shell** for the modular catalog (empty/coming-soon block) | Full data-driven catalog from `services.json` is Phase 3 |
| `/{lang}/galeria` | **Shell** — page chrome + empty "Coming soon / updates from Discord" state + CTA | Masonry + lightbox from `gallery.json` is Phase 4 |
| `/{lang}/terminos` | **Full** Terms content, both languages, EN draft + reviewer banner | I18N-04; ES verbatim, EN flagged for legal review |
| `/` (root) | Redirect only — language detect → `/es/` or `/en/` (D-04) | No unprefixed canonical pages (D-01) |
| `/404` (localized) | Branded 404 using error-state copy + CTA | New this phase (i18n routing surfaces it) |

**Responsiveness (PLAT-04):** all pages fully responsive; mobile is single-column, nav collapses to hamburger drawer, touch targets ≥44px, hero/section type scales via `clamp()`. Test at ~360px, ~768px, ~1280px.

**Animation-readiness (do, don't):** keep `reveal` hooks and stable section/element structure so Phase 2 can attach GSAP/ScrollTrigger and View Transitions without re-authoring markup. Do **not** ship the WebGL shader, Lenis, cursor effects, or reveal transitions in Phase 1.
