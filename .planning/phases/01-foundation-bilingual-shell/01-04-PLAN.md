## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner → GitHub Pages (production cutover) | The cutover repoints production Pages to the Actions build; a misconfig could drop the custom domain |
| legacy inbound links → site | Old unprefixed/anchor URLs from external sites/SEO are redirected |
| Terms content → public | Legal text published as an unreviewed EN draft |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02b | Tampering | CNAME / custom domain at production cutover | mitigate | `public/CNAME` re-emits `nocturna-avatars.site` on every build; the cutover checkpoint explicitly verifies the domain remains bound after switching the Pages source (D-09, PLAT-02). Documented rollback: revert Pages Source to the previous branch. |
| T-01-11 | Repudiation / Legal | EN Terms published as an unreviewed draft | mitigate | EN `/terminos` carries a prominent, persistent "pending legal review" reviewer banner (D-13) so the draft status is unambiguous to any visitor; ES (authoritative) is verbatim. Banner removal is gated on the user's later legal sign-off, out of scope this phase. |
| T-01-12 | Tampering / Open redirect | legacy `/index.html` and root redirects | mitigate | Redirect targets are hard-coded literal local paths (`/es/`); no external or user-derived value is used to build the destination — no open-redirect surface. |
| T-01-13 | Information Disclosure | Terms copy rendered from JSON | mitigate | Terms strings render via Astro auto-escaping interpolation; bolded clauses use static template markup, not `set:html` from data. Author-controlled content only. |
| T-01-SC | Tampering | npm dependencies (this plan adds none) | mitigate | No new packages; locked tree from plan 01 governs. |
