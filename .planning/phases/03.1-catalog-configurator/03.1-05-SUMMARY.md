# Phase 3.1 Plan 05: cart.ts Cart Engine Summary

**One-liner:** Vanilla TypeScript cart engine with module-level Map state, full DOM sync (pill badge, drawer item list + total), and WR-01 drawer open/close; replaces the Plan 04 stub.

## What Was Built

### Task 1 — cart.ts: Map state, add/remove/qty, syncCartUI, drawer open/close

Replaced `src/scripts/cart.ts` stub with the full cart engine:

**Section 1 — Types and module-level state:**
- `CartEntry` interface (`name`, `price`, `qty`)
- `const cart = new Map<string, CartEntry>()` at module level — persists across navigations
- `let cartDocListenersBound = false` at module level — guards document-level bindings

**Section 2 — Cart state functions (pure, no DOM):**
- `addItem(id, name, price, repeatable)` — idempotent for non-repeatable, increments for repeatable
- `removeItem(id)` — deletes entry from Map
- `setQty(id, qty)` — removes if qty <= 0, otherwise updates
- `getCount()` — sum of all qty values (used for badge)
- `getTotal()` — sum of `parseInt(price) * qty` for numeric-priced items only

**Section 3 — `syncCartUI()`:**
Re-queries all DOM nodes fresh each call (no stale closed-over refs). Updates:
- Badge count text
- Pill aria-label (bilingual, based on `document.documentElement.lang`)
- Pill visibility: removes [hidden] + adds `.cart-pill--visible` when count > 0; adds `.cart-pill--hiding` + sets [hidden] on animationend when count = 0 (or immediate if prefers-reduced-motion)
- Drawer item list: rebuilds via `createElement` + `textContent` (XSS-safe); each row has name, optional qty span (×N), price (`$N USD` or `Cotizar`), remove button with `data-remove-id`
- Drawer total span
- Catalog row button state (`catalog-row__cart-btn--added` class, text Agregar/Quitar or Add/Remove) and qty-count text

**Section 4 — `bindCartRowControls()`:**
- `.cart-add-trigger` click: toggle add/remove for non-repeatable items
- `.qty-btn--dec` click: decrement or remove
- `.qty-btn--inc` click: increment or add (repeatable)
- Event delegation on `.cart-drawer__items` for dynamically rendered remove buttons

**Section 5 — `openDrawer()` / `closeDrawer()` (WR-01 pattern):**
- `openDrawer`: guards `getCount() === 0`, removes [hidden] before `requestAnimationFrame` adds `.active`, sets `aria-hidden="false"`, locks body scroll, focuses first focusable
- `closeDrawer`: removes `.active` first, sets `aria-hidden="true"`, clears body scroll, re-adds [hidden] on `transitionend` filtered by `propertyName === 'transform'`, returns focus to pill

**Section 6 — `bindPillClick()` / `bindDrawerClose()`** — per-element, fresh each page-load

**Section 7 — `bindEscapeKey()` / `bindBackdropClick()`** — document-level, inside `if (!cartDocListenersBound)` guard; re-query DOM at event time

**Section 8 — `bindDrawerTicket()`** — closes drawer, then calls `openCartModal()` after 50ms delay

**Sections 9 + 10 — Stubs + registration:**
- `openCartModal()` and `closeCartModal()` stubs (filled in Plan 03.1-06)
- `document.addEventListener('astro:page-load', initCart)` registration

**Build result:** 12 pages, 0 TypeScript errors, 0 build warnings
