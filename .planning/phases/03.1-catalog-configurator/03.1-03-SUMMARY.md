## What Was Built

### Task 1 — CartSummaryModal.astro

Created `src/components/CartSummaryModal.astro` — a hidden modal overlay that activates when cart.ts calls `openCartModal()` after the user clicks "Abrir Ticket" in the CartDrawer.

**HTML anatomy:**
- Outer div: `class="dc-overlay cart-modal-overlay"` with `id="cartModalOverlay"`, `data-cart-modal-overlay`, `hidden`, `aria-hidden="true"`, `role="dialog"`, `aria-modal="true"`, `aria-labelledby="cartModalTitle"` — full WR-01 pattern
- Inner div: `class="dc-modal cart-modal"` — inherits dc-modal base sizing from chrome.css
- `dc-body cart-modal__body` flex column layout
- `h3.dc-title.cart-modal__title` with `id="cartModalTitle"` for aria-labelledby binding
- `.cart-modal__list` — empty DOM insertion point for cart items (populated by cart.ts via textContent)
- `.cart-modal__total` — empty DOM insertion point for total line (populated by cart.ts)
- `.cart-modal__disclaimer` — bilingual static text
- `.cart-modal__actions` row: copy button (`data-cart-copy`) + Discord link (`class="cart-modal__discord"` only)
- `button.dc-dismiss` with `data-cart-modal-dismiss` — reuses dc-dismiss styles from chrome.css

**Scoped CSS overrides (only what chrome.css doesn't provide):**
- `.cart-modal { width: 480px; max-width: 94vw }` — wider than 380px Discord modal
- `.cart-modal__body { display: flex; flex-direction: column; gap: var(--space-sm) }` — flex column layout
- `.cart-modal__title { text-align: left }` — overrides dc-body center alignment
- `.cart-modal__list`, `.cart-modal__total`, `.cart-modal__disclaimer` — typography and color per UI-SPEC
- `.cart-modal__copy` with hover/focus-visible and `.cart-modal__copy--copied` transient state (red border/text for 1.5s feedback)
- `.cart-modal__discord` red fill CTA (no dc-open-btn class)

**data-* targeting attributes for cart.ts:**

| Attribute | Element | Purpose |
|-----------|---------|---------|
| `data-cart-modal-overlay` | Outer overlay div | querySelector hook for open/close |
| `data-cart-copy` | Copy button | clipboard copy trigger |
| `data-cart-modal-dismiss` | dc-dismiss button | close modal trigger |

**Bilingual:** Heading, disclaimer, button labels all rendered conditionally via `lang` prop (`'es' | 'en'`).

## Known Stubs

- `.cart-modal__list` and `.cart-modal__total` are empty `<div>` elements — this is intentional. Cart.ts (Plan 03.1-05) populates these via `textContent` at runtime from cart state. They are DOM insertion points by design, not placeholder stubs. The plan's threat model (T-03.1-03) requires textContent (not innerHTML) to prevent XSS.
- CartSummaryModal is not yet mounted in any page — that happens in Plan 03.1-04 (ServicesPage integration). Build passes because Astro compiles the component file but it is not imported anywhere yet.
