# Phase 2 — UI Design Contract

> Visual and interaction contract for Phase 2 (Experimental Motion Layer). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** This phase adds a **motion + interaction layer** onto the already-shipped Phase 1 shell. It introduces **no new pages, no new brand tokens, and no new copy surfaces** — it animates existing markup (FX-01 Lenis smooth scroll, FX-02 GSAP/ScrollTrigger reveals, FX-03 one WebGL hero shader, FX-04 interactive cursor, NAV-04 Astro View Transitions). The visual identity (colors, fonts, spacing, type scale) is **inherited verbatim from Phase 1's locked design system** (`src/styles/tokens.css`). This contract therefore formalizes the **motion, timing, state, and degradation contract** — the dimension this phase actually decides — and re-states the inherited static tokens only as governing constraints.
>
> **Through-line (locked, D-01/D-09/D-17/D-18):** one cohesive **glitch / chromatic-aberration** visual language across the hero shader, the page-transition flash, the micro-interaction flicker accent, and the first-load intro. These are not four separate effects — they read as one motif.
>
> **Hard constraint (D-19/D-20/D-22):** the **"Abrir Ticket" conversion path must stay reachable and the site must stay fast in every motion state.** Performance wins ties. Hero text + CTA render and work before any motion JS.

## Spacing Scale

**Inherited verbatim from Phase 1 (`tokens.css`).** This phase declares **no new spacing tokens** and motion must not introduce off-scale layout offsets.

| Token | Value | Usage |
|-------|-------|-------|
| 3xs | 4px | Hairline gaps, icon insets |
| 2xs | 8px | Compact element spacing |
| xs | 12px | Chip/pill padding |
| sm | 16px | Default element spacing |
| md | 24px | Card padding, sub-group gaps |
| lg | 32px | Generous card padding, inline gutters |
| xl | 48px | Page side gutters (max) |
| 2xl | 64px | Nav height (`--nav-h`); major in-section breaks |
| 3xl | clamp(60px, 10vw, 120px) | `--section-pad` vertical rhythm |

**Motion-spacing rules (this phase's only additions — kinematics, not layout):**
- **Reveal travel distance** (offset slides, D-10): on-scale values only — entrances translate from **24px / 32px / 48px** offsets (`--space-md` / `--space-lg` / `--space-xl`). No arbitrary px.
- **Magnetic pull radius / displacement** (D-07): the magnetic catch zone extends ~**48px** (`--space-xl`) around an interactive element; max element displacement toward the cursor is **≤ 8px** (`--space-2xs`) so layout never visibly shifts and click targets stay honest.
- **Touch targets unchanged:** 44×44px minimum (`--touch-min`) — cursor magnetism must **never** shrink or move a hit area on touch (cursor is desktop-only, D-08) and must not interfere with the FloatingCTA / Discord-modal click targets (integration point).

Exceptions: none beyond the inherited 44px touch-target and `clamp()` gutter exceptions already sanctioned in Phase 1.

## Typography

**Inherited verbatim from Phase 1.** No new sizes or weights. The contract here is **how type animates**, not its scale.

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 16px (15px dense) | 400 | 1.7 | Inter |
| Label | 10–12px uppercase, tracked | 400 | 1.4 | Space Mono |
| Heading | clamp(24px,5vw,44px); 20–28px card | 400 | 1.15 | Permanent Marker |
| Display | clamp(46px,11.5vw,240px); 33px nav | normal | 0.9 | A Another Tag |

**Type-in-motion contract:**
- **Display headings split per word/char and stagger in (D-11)** — the signature use of `A Another Tag`. Split-text mechanics (mask/clip wipe + offset, D-10) are an implementation detail (D-disc), but the **animated unit is the word/char**, not the whole line.
- **Reduced-motion (D-21):** split-text reveals collapse to a **single gentle fade** of the whole heading — no per-char stagger, no clip wipe.
- **No layout shift / FOUT discipline:** split-text must not reflow line breaks or cause CLS. Reserve final layout first, then animate (honors perf budget, D-20). Fonts the intro waits on (D-18) must not block paint of the readable hero.
- **No new text in motion:** per the i18n constraint (code_context), the cursor carries **no label** and the intro uses no new copy strings — so no new dictionary entries are required this phase.

## Color

**Inherited verbatim from Phase 1's 60/30/10 split.** Motion introduces **no new color**; the shader and effects draw exclusively from existing tokens.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--navy #0a0c14` | Page void; **shader base field** (D-02) |
| Secondary (30%) | `--navy-mid #10131e`, `--navy-light #181c2e`, `--navy-surface #141828` | Cards, nav, footer, modals |
| Accent (10%) | `--red #c0192c` (base), `--red-glow #e8223b` (glow/bleed), `--red-dark #7a0f1a`, `--red-soft rgba(192,25,44,0.12)` | See reserved-for list |
| Foreground | `--white #f0eae4`, `--white-dim #9a9198` | Text (outside the surface budget) |
| Destructive | reuses `--red` | **No destructive data actions exist in Phase 2** (see Copywriting) |

**Accent (red) reserved-for — motion additions to the Phase-1 list (never "all effects"):**
1. **WebGL hero shader bleed (D-02):** navy/black field with **red accents only** — `--red #c0192c` chromatic bleed, `--red-glow #e8223b` for glitch-burst emphasis. Red must stay a *minority bleed*, never flood the hero (keeps headline + CTA legible per D-04).
2. **Chromatic-aberration channel split:** the glitch motif's RGB-split offset may render a red fringe on transitions (D-17), the micro-interaction flicker (D-09), and the intro (D-18) — kept brief and low-coverage.
3. **Persistent CTA pulse (D-19):** the floating "Abrir Ticket" subtle pulse/entrance uses the accent red glow — reinforces conversion, stays ≤10% coverage.

Everything else (cursor, reveals, parallax, tilt) is **achromatic / blend-mode-driven**, not red. The custom cursor uses **`mix-blend-mode: difference`** (D-06) — it derives contrast from whatever is beneath it (invert), so it introduces no new hue. Red stays *the action color*; motion must not dilute it by tinting non-CTA effects red.

**Legibility guard (D-04, hard):** the shader sits **behind a contrast/vignette overlay** so the hero headline + CTA always pass AA. `--white #f0eae4` foreground on the darkened shader region must remain ≥ AA contrast at all glitch intensities (test at peak glitch-burst). The no-WebGL fallback (static grain/gradient) must meet the same contrast.

## Copywriting Contract

**This phase introduces no new copy surfaces.** All visible strings are inherited from Phase 1's bilingual dictionaries (`src/i18n/`, ES authoritative / EN draft). Motion is **languageless** by decision (no cursor label, no new intro copy — code_context constraint). The contract below documents the few motion-adjacent states.

| Element | Copy | Notes |
|---------|------|-------|
| Primary CTA (unchanged) | **Abrir Ticket** / **Open a Ticket** | The conversion action; persistent floating CTA stays reachable in every motion state (D-19). Pulse is visual only — no copy change. |
| Intro / first-load (D-18) | **no copy** — visual glitch-tag only (~1s) | Uses the brand mark visually if anything; **skippable**, instant on repeat visits, disabled under reduced-motion, never blocks CTA/content. If a skip affordance needs a label, reuse an existing dictionary key (e.g. a "Saltar" / "Skip" entry) rather than hardcoding — but a non-text click/tap-to-skip is preferred to avoid a new string. |
| Empty / error / loading states | **inherited unchanged** | Gallery/servicios shells keep their Phase-1 "Muy pronto / Coming soon" empty copy. Motion does not add data, so it adds **no new empty/error/loading copy**. A no-WebGL or reduced-motion render is a *silent* graceful fallback — **no apology/notice text** is shown. |

**Destructive actions:** **None in Phase 2.** Motion creates, edits, or deletes no data; there are no forms, writes, or confirmations. The only dismiss-style control (intro **skip**) is non-destructive and needs no confirmation.

## Motion & Interaction Contract (phase-specific — the core of this spec)

> This is the dimension Phase 2 decides. Every row maps to a locked CONTEXT decision (D-xx). Timing/easing **values** below are the prescribed defaults; exact GSAP/Lenis tuning is implementation detail (D-disc) but must honor the stated intent and budget.

### Global motion principles (apply to all effects)

| Principle | Contract | Source |
|-----------|----------|--------|
| Progressive enhancement | Hero text + CTA render and are interactive **before** any motion JS. Lenis / GSAP / shader / cursor load **deferred after first paint** (follow the `src/scripts/chrome.ts` deferred-entry pattern). Site fully usable with JS disabled or slow. | D-20 |
| Reduced-motion (partial reduce) | On `prefers-reduced-motion: reduce`: **disable** smooth-scroll inertia, bold reveals, the live shader, and the custom cursor. **Keep** gentle fades + a **static** shader image. All content/CTA fully present. | D-21 |
| Touch / pointer gating | Custom cursor + magnetism are **desktop / fine-pointer only**, gated by `@media (pointer: fine) and (hover: hover)`. Touch keeps native cursor, no magnetism. | D-08 |
| Mobile motion | Full motion incl. live shader, BUT shader runs **ambient/autonomous** on touch (no pointer to follow) and **falls back to the static grain image** if it can't meet the hard perf budget on low-end devices. **Performance wins ties.** | D-22 |
| CTA survivability | The floating "Abrir Ticket" CTA stays persistent + clickable in every motion state (intro, transition, scroll, reduced-motion, no-WebGL). Cursor magnetism must not steal or shift its hit target. | D-19 |
| One motif | Glitch / chromatic aberration is the shared language across shader, transitions, micro-interactions, and intro — tuned to read as one system. | D-01/D-09/D-17/D-18 |

### Hero WebGL shader (FX-03)

| Property | Contract | Source |
|----------|----------|--------|
| Aesthetic | Grain + glitch/chromatic: scanlines, chromatic aberration, digital glitch bursts. Harmonizes with (does not double) the existing film-grain overlay. | D-01 |
| Color | Navy/black field (`--navy #0a0c14`) with red bleed (`--red #c0192c`, glow `--red-glow #e8223b`) — minority accent only. | D-02 |
| Reaction | Mouse-reactive (distorts toward cursor); **pointer input throttled** (e.g. rAF-coalesced, ~60fps cap) for perf. | D-03 |
| Legibility | Sits **behind a contrast/vignette overlay**; headline + CTA always AA-readable. | D-04 |
| Fallback | **No-WebGL → static grain/gradient image** (progressive enhancement; hero fully readable without WebGL). Same fallback under reduced-motion and low-end mobile budget miss. | D-04/D-21/D-22 |
| On scroll | Parallax fade + glitch-intensity ramp, then dissolve into next section. **Not a scroll-pin** (cheap, cinematic). | D-05 |

### Cursor & micro-interactions (FX-04)

| Property | Contract | Source |
|----------|----------|--------|
| Custom cursor | Blend-mode **`difference`** invert circle — high-contrast over text/images/shader. Desktop/fine-pointer only. | D-06/D-08 |
| Hover behavior | **Magnetic pull** on interactive elements (CTA, links, cards) + **cursor grows** over them. Pull radius ~48px, element displacement ≤8px (see Spacing). Draws the eye toward the conversion CTA. | D-07 |
| Micro-interactions | A **tasteful, cohesive set** on buttons / nav / package cards: lift · underline-draw · a small **glitch flicker** echoing the hero shader. Cohesive, not noisy. | D-09 |

### Scroll reveals & smooth scroll (FX-01, FX-02)

| Property | Contract | Source |
|----------|----------|--------|
| Smooth scroll (Lenis) | **Smooth but snappy** — short smoothing duration / light inertia (target ~0.8–1.0s duration, low lerp). Never slows the path to the CTA. Disabled inertia under reduced-motion. | D-13/D-21 |
| Reveal energy | **Bold + graffiti**: staggered entrances with clip/mask "spray" wipes + offset slides (24/32/48px travel). | D-10 |
| Heading reveals | Display headings (`A Another Tag`) animate **split per word/char**, staggered. | D-11 |
| Reveal concentration | **Strongest reveals on the landing's showcase moments** (featured work, packages summary, gallery teaser). Dedicated pages (`/servicios`, `/galeria`, `/terminos`) get a **subtler** treatment. | D-12 |
| Hooks | Reuse Phase-1's pre-placed inert `reveal` class hooks + neutral `loading="lazy"` markup — do not re-author markup. | code_context |

### Landing choreography (bespoke moments on top of D-10)

| Section | Contract | Source |
|---------|----------|--------|
| Gallery teaser | Scroll-driven **horizontal marquee/track** previewing `/galeria`. | D-14 |
| Package cards | Staggered reveal + **subtle 3D tilt/hover** (premium/tactile pricing tiers). | D-15 |
| Featured work | **Parallax depth** against background on scroll. | D-16 |

### Page transitions (NAV-04) & chrome behavior

| Property | Contract | Source |
|----------|----------|--------|
| Transition style | **Quick glitch wipe** — fast wipe + brief glitch/chromatic flash echoing the hero shader; kept short so navigation stays snappy. Astro View Transitions. Must **refresh ScrollTrigger** and reconcile Lenis scroll position on transition (integration point). | D-17 |
| First-load intro | **Brief glitch-tag intro (~1s) on first visit only**, while shader+fonts init. **Skippable**, instant on repeat visits, **disabled under reduced-motion**, never blocks CTA/content. | D-18 |
| Nav in motion | **Hide-on-scroll-down / show-on-scroll-up** (reclaims space for immersion). | D-19 |
| Floating CTA in motion | Stays **persistent** with a subtle **pulse/entrance** so conversion stays alive in every motion state. | D-19 |

### Performance budget (hard constraint — perf wins ties)

| Rule | Contract | Source |
|------|----------|--------|
| Load discipline | Motion libs deferred/code-split after first paint; hero readable + CTA clickable pre-JS. | D-20 |
| Shader cost | One shader, not a 3D scene (Three.js deferred to v2). Must not double the grain-overlay cost. Throttle pointer updates. | D-03/D-22, ROADMAP |
| Degradation order | When budget can't be met: drop live shader → static grain image **before** dropping legibility or the CTA. On low-end mobile, fall back automatically. | D-22 |
| Concrete thresholds | Specific FPS / bundle-size / TTI thresholds are implementation detail for planner/executor (D-disc), but the live shader must hold ~60fps on mid-range desktop and degrade gracefully below it. | D-disc |
