    - Compute `liveShader = webglOK() && !prefersReduced`. If false, leave the static `<img>` fallback visible and do NOT init (D-04/D-21).
    - Get the context via `canvas.getContext('webgl2', { failIfMajorPerformanceCaveat: true, antialias: false, alpha: true, powerPreference: 'high-performance' })`; if null → keep fallback, return (Pitfall 5).
    - Compile/link the quad + glitch programs (import GLSL via `?raw`). On compile/link failure → keep fallback, return.
    - Pointer (D-03): only when `finePointer`, bind a `pointermove` handler that CACHES the latest coords; read them ONCE per rAF frame to set `u_mouse` (throttled — never set the uniform synchronously per move).     - Once the first frame renders, toggle the hero state so the canvas is shown and the `<img>` fallback hidden (Task 1's data state).

    `destroyHeroShader()`: `cancelAnimationFrame`, remove the pointermove + contextlost listeners, lose the WebGL context (`getExtension('WEBGL_lose_context')?.loseContext()`), and restore the static-fallback default state so a re-init starts clean. Wire `initHeroShader()`/`destroyHeroShader()` into the Plan 01 controller's `initMotion`/`teardownMotion`.

| GPU/driver → page | WebGL2 context may be software-rendered, lost, or unavailable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-GLSL | Tampering/Injection | pointer → shader uniform | mitigate | `u_mouse` is numeric clientX/Y normalized to resolution before upload — no string/shader-source injection surface; GLSL is local/bundled via `?raw`, never fetched remotely (RESEARCH Security V5: input is clamped numerics) |
| T-02-DOS-GPU | Denial of Service (self-inflicted UX) | rAF shader loop on weak GPU | mitigate | `failIfMajorPerformanceCaveat: true` drops software GPUs; frame-budget guard + `webglcontextlost` swap to static fallback (perf wins ties, D-22); rAF cancelled on teardown |
| T-02-CTA | Availability of conversion path | shader covering hero | mitigate | Legibility overlay keeps headline + CTA AA at peak glitch; degradation order drops the shader BEFORE legibility/CTA; CTA lives in static HTML above the canvas |
| T-02-REMOTE | Tampering | shader assets | accept→mitigate | No remote shader fetch; GLSL bundled locally — keeps static GH-Pages CSP posture intact |
| T-02-INFO/AUTH/REP | Info disclosure / Auth / Repudiation | n/a | accept | No data, auth, or transactions in a shader (RESEARCH Security Domain) |
