## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering (XSS) | JS-populated quick-view rows (name/description/editor) | mitigate | `createElement` + `textContent` only, never `innerHTML`, in store.ts |
| T-06-02 | Tampering / Elevation | `checkoutUrl` -> buy anchor `href` (`javascript:`/`data:` risk) | mitigate | Validate `checkoutUrl.startsWith('https://')` before assigning href; else render the `linkUnavailable` disabled state |
| T-06-03 | Tampering (reverse tabnabbing) | `target="_blank"` buy link to Jinxxy | mitigate | `rel="noopener noreferrer"` on the buy anchor |
</threat_model>
