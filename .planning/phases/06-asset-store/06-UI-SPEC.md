# Phase 6 — UI Design Contract: Asset Store

> Visual and interaction contract for the `/tienda` ES · `/en/store` EN storefront.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This phase adds NO new design primitives.** It composes the established
> "Refined Street Editorial" system (Phase 02.1, `src/styles/theme.css`) and the
> verified Phase 3.1 cart interaction patterns. This spec pins which existing
> tokens/patterns the store must reuse, and the few store-specific contracts
> (product card, quick-view, NSFW reveal, purchase cart, image fallback).

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Astro static + Tailwind v4 CSS-first; React/shadcn explicitly excluded — 02.1 decision) |
| Preset | not applicable |
| Component library | none (hand-authored `.astro` components + vanilla-TS client modules) |
| Icon library | inline hand-authored SVG (stroke `currentColor`, matches CartPill/CartDrawer glyphs) |
| Font | Space Grotesk (display) · A Another Tag / Permanent Marker (graffiti accent) · Inter (body) · Space Mono (labels) |
| Token source of truth | `src/styles/theme.css` `@theme` block (do NOT introduce new hex or ad-hoc px) |
| shadcn gate | Not applicable — stack is Astro, not React/Next/Vite; no `components.json`. Registry safety: not applicable. |

**Rule for executor:** every color is a `var(--color-*)` token; every spacing value is a `var(--space-*)` token; every font is a `var(--font-*)` token. New store CSS targets the canonical `--color-*` tokens directly (not the legacy short aliases).

## Spacing Scale

Declared values (from `theme.css` `@theme`, 8-point base):

| Token | Value | Usage in store |
|-------|-------|-------|
| `--space-3xs` | 4px | Icon gaps, badge inset, tight inline |
| `--space-2xs` | 8px | Compact chip/tag spacing, card meta gap |
| `--space-xs` | 12px | Card interior compact gap (established exception, see below) |
| `--space-sm` | 16px | Default element spacing, card padding, drawer row gap |
| `--space-md` | 24px | Card block spacing, drawer header/footer gaps |
| `--space-lg` | 32px | Grid gap, drawer padding, section inner padding |
| `--space-xl` | 48px | Major section breaks |
| `--space-2xl` | 64px | Page-level vertical rhythm |
| `--space-3xl` | clamp(60px, 10vw, 120px) | Page section padding (`--section-pad`) |

**Exceptions (inherited from the established system — do not add new ones):**
- `--space-xs` = 12px — an intentional non-8 step already in the system for compact card interiors.
- Fluid clamps for page gutters/section padding (`--page-gutter`, `--section-pad`) — responsive by design.
- `--touch-min` = 44px minimum interactive target (a11y, PLAT-04). Store cart pill is 52px (matches existing CartPill). NSFW reveal button and card add-to-cart control must be ≥44px tall.

## Typography

Declared roles for the store (map to `theme.css` type tokens). **Two weights only: 400 (Inter body) + 700 (Space Grotesk display / Space Mono labels).**

| Role | Token | Size | Font / Weight | Line Height |
|------|-------|------|---------------|-------------|
| Body | `--type-body` | 16px | Inter 400 | 1.7 (`--lh-body`) |
| Label | `--type-label` → 11–14px | clamp(10px,1.4vw,12px) eyebrows; 14px price/editor mono | Space Mono 700, uppercase + letter-spacing for eyebrows | 1.4 (`--lh-label`) |
| Heading (product/card name) | `--type-card-title` | clamp(20px, 3vw, 28px) | Space Grotesk 700 | 1.15 (`--lh-heading`) |
| Display (page title) | `--type-heading` | clamp(24px, 5vw, 44px) | Space Grotesk 700 | 1.15 (`--lh-heading`) |

**Store-specific typographic contracts:**
- Product **price** renders via component-added `$` + ` USD` suffix (same convention as services.json / `formatEntryPrice` in cart.ts): `${price} USD`, Space Mono 700, `font-variant-numeric: tabular-nums`.
- Editor credit `por {editor}` / `by {editor}` — Space Mono, `--type-label` size, `--color-white-dim`. Plain text, never a link (D-16).
- Section eyebrow / cart eyebrow — Space Mono 11px, `letter-spacing: 0.2–0.24em`, `text-transform: uppercase`, `--color-red-on-ink`.
- Product **description** in quick-view — Inter 400, 16px, 1.7 line-height, `--color-paper-on-ink` (off-white).
- The graffiti face (`--font-tag`) is a signature accent ONLY (wordmark / a single page tag) — never for product names, prices, or body. Do not introduce it into cards.

## Color

60/30/10 split — the store lives entirely on the dark editorial field (no bright surfaces; the whole site is dark/moody per 02.1 4th-pass user feedback).

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `--color-ink` | #0a0c14 | Page background, store field |
| Secondary (30%) | `--color-ink-raised` / `--color-paper` | #10131e / #11141f | Product cards, quick-view surface, cart drawer panel |
| Accent (10%) | `--color-red` | #c0192c | Reserved list below |
| Foreground | `--color-white` / `--color-white-dim` | #f0eae4 / #9a9198 | Primary text / secondary meta text |
| Hairline | `--color-border` | white @ 6% | Card borders, drawer rules, dividers |

**AA-safe red variants (use these for small red text, never raw `--color-red` on dark):**
- On ink field → `--color-red-on-ink` (#e84a5e, ≥4.5:1) for eyebrows, in-drawer qty, small red labels.
- On paper field → `--color-red-on-paper` (#c0192c on #241d15) for tags/numbers in paper sections.
- Raw `--color-red` (#c0192c) is for FILLS, rules, and the CTA buttons only.

**Accent (red) reserved for — explicit list, nothing else:**
1. The purchase CTA fills — "Comprar en Jinxxy" / "Buy on Jinxxy" buttons and the store cart pill (52px red circle, matches CartPill).
2. `featured: true` product card treatment — the single highlight border + "Destacado" / "Featured" badge (mirrors PackageCard's "Más popular" — the only red-accented tier).
3. Small red mono eyebrows/labels (via the AA-safe on-ink/on-paper reds): section eyebrow, cart eyebrow, in-drawer item qty (`×N`).
4. Cart count badge accent context (the badge itself is navy-on-red, matching CartPill).
5. Focus/hover glow on red controls only.

Red is NOT used for: product card body, add-to-cart control default state (secondary/outline styling — see interaction contract), the NSFW reveal button, drawer item names, or generic interactive elements.

| Semantic | Token | Usage |
|----------|-------|-------|
| Destructive | (no dedicated destructive color) | Cart item removal is a low-stakes, reversible single-click `×` (reuses `.cart-drawer__item-remove` register: `--color-white-dim` → `--color-red-on-ink` on hover). No red-fill destructive button, no confirmation modal — matches the verified cotización pattern. |

## Interaction & Component Contracts

Store-specific behavior the executor must implement. All reuse the verified Phase 3.1 mechanics (copy, do not refactor cart.ts — RESEARCH Pattern 1).

### Product grid + card (`StorePage.astro` + `ProductCard.astro`)
- Responsive grid: mirror `GalleryPage` / catalog rhythm. Cards on the `--color-ink-raised` surface with `--color-border` hairline. Grid gap `--space-lg`; responsive at 375 / 768 / 1024 / 1440.
- Card content (D-08): `images[0]` thumbnail (fixed aspect-ratio box to prevent CLS) + product name (`--type-card-title`) + price + `por {editor}`. Whole card opens the quick-view; add-to-cart is a distinct control that does NOT trigger the quick-view (stop propagation).
- Ordering (D-09): `featured: true` pinned first, then newest-first by `date` — resolved at build in the `.astro` component (RESEARCH Pattern 4).
- `featured` card = the single red highlight border + "Destacado"/"Featured" badge (the only red-accented card).

### Quick-view modal (`QuickViewModal.astro`)
- Reuses the `dc-overlay` overlay + `trapFocus` + Escape/backdrop-close pattern (D-07). `role="dialog"`, `aria-modal="true"`, `aria-labelledby` the product name. z-index = the existing modal layer (`dc-overlay` 10000 — above the cart drawer's 8001).
- Content: image gallery (`images[]`), full description (Inter 16/1.7), price, editor credit, primary "Comprar en Jinxxy" + secondary "Agregar al carrito".
- XSS guard (T-03.1-08): any JS-injected rows/nodes use `createElement` + `textContent`, never `innerHTML`.

### NSFW reveal (D-10 — Claude's discretion on the treatment)
- `nsfw: true` cards render with a strong `filter: blur(…)` + a dark scrim so nothing is legible pre-reveal, and a `<button>` labeled "Mostrar contenido sensible" / "Show sensitive content" (keyboard + screen-reader operable, ≥44px).
- Reveal is per-card, per-session — **no global toggle, no persisted 18+ state**. Quick-view of an NSFW product inherits the card's reveal state.
- The blur *filter* is fine under reduced motion; only the *transition* is gated — under `prefers-reduced-motion: reduce` the unblur is instant (no animated transition).

### Purchase cart — sibling module `store-cart.ts` (D-17/D-19/D-20)
- Separate namespaced DOM contract so it never touches the cotización: `#storeCartPill`, `.store-cart-pill__badge`, `#storeCartDrawer`, `#storeCartBackdrop`, `.store-cart-drawer__items`, `[data-store-cart-total]`.
- **Store cart pill:** 52px red circle, `z-index` matching CartPill (~905), fixed bottom-right; count badge navy-on-red appears only once items are added; badge pop animation gated to `prefers-reduced-motion: no-preference` (copy CartPill exactly).
- **Drawer:** slide-in right, `width: min(430px, 92vw)`, `--color-ink-raised` panel, `--color-border` left rule, backdrop `z 8000` / drawer `z 8001` (mirror CartDrawer). WR-01 open/close: unhide `[hidden]` BEFORE `.active`; on close re-add `[hidden]` only on `transitionend` filtered by `e.propertyName === 'transform'`. `data-lenis-prevent` on backdrop + drawer.
- **Drawer rows (D-18 = NO branch):** each selected product row shows name + price + a per-item "Comprar en Jinxxy" link (`target="_blank" rel="noopener noreferrer"`). Footer = running total labeled "Total (referencia)" + the footer note (checkout happens per-item on Jinxxy). **No single "buy all" button** (popup-blocked; RESEARCH anti-pattern).
- **Persistence (D-20):** `localStorage` key `nocturna-store-cart`; on hydrate, reconcile stored ids against the current `store.json` (drop unknown ids, refresh name/price/checkoutUrl from data — Pitfall 2; the cart entry carries no image, so rows stay text-only). The cotización cart stays reset-on-refresh (do NOT add persistence to it).
- View-Transitions safe: `astro:page-load` re-init with per-load guard + `astro:before-swap` reset (copy cart.ts:735-767).

### Image fallback (D-11 — Claude's discretion)
- Preview `<img>` hotlinked from Jinxxy CDN with `loading="lazy" decoding="async"` and an explicit aspect-ratio box (no CLS). On `error`, swap `src` to a local branded placeholder (`public/store/placeholder.svg`) with alt "Imagen no disponible" / "Image unavailable".

### Security-adjacent UI guard
- Validate `checkoutUrl` starts with `https://` before rendering any buy control; otherwise render the disabled "Enlace no disponible" / "Link unavailable" state (Pitfall 5). All outbound Jinxxy links carry `rel="noopener noreferrer"`.

## Accessibility & Motion

- Responsive at 375 / 768 / 1024 / 1440; AA contrast on the dark field using the AA-safe red variants for small red text (STORE-05, PLAT-04).
- `prefers-reduced-motion: reduce` respected on: NSFW blur/unblur (instant), cart badge pop (skipped), drawer slide (the system's reduced-motion path already short-circuits `requestAnimationFrame` activation).
- All interactive controls keyboard-operable with visible `:focus-visible` (2px `--color-white` outline, `outline-offset`), matching existing chrome. Focus trapped in quick-view and cart drawer; Escape + backdrop close both.
- "Abrir Ticket" Discord path stays reachable on the store page (STORE-05) — the store cart pill sits alongside (not replacing) the FloatingCTA, same as /servicios.
