## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage -> cart state | Client-controlled storage rehydrated into the cart on load |
| store.json island -> drawer DOM | Staff-authored product data injected into drawer rows at runtime |
| checkoutUrl -> per-item `<a href>` | Staff-authored URL becomes a live outbound link per row |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering (XSS) | JS-built drawer rows (name/price/link) | mitigate | `createElement` + `textContent` only, never `innerHTML`, in store-cart.ts |
| T-06-02 | Tampering / Elevation | `checkoutUrl` -> per-item buy anchor href | mitigate | Assign href only if `checkoutUrl.startsWith('https://')`; else render `linkUnavailable` disabled span |
| T-06-03 | Tampering (reverse tabnabbing) | per-item `target="_blank"` Jinxxy links | mitigate | `rel="noopener noreferrer"` on every row link |
| T-06-04 | Tampering | localStorage cart contents (edit ids/prices) | mitigate | Reconcile stored `[id, qty]` against the canonical `[data-store-products]` island on hydrate; drop unknown ids; refresh name/price/url from data (never trust stored price/url) |
</threat_model>
