<objective>
Build `CatalogSection.astro` — the new component that renders the modular service catalog from
`services.json` — and wire it into `ServicesPage.astro`, replacing the `EmptyState` placeholder.

The catalog is the main deliverable of Phase 3. It renders each category as:
- A section-tag header (Space Mono, red accent, following the established pattern)
- A category title below
- If the category has items: an editorial row list (name left, price right, 1px hairlines; "Cotizar"
  in red for the `"cotizar"` sentinel price)
- If the category has no items: the `EmptyState` component with bilingual "Próximamente" copy

All 5 categories ship empty at first deploy (D-05) — all 5 show the empty state. Staff populate
items in `services.json` when prices are agreed; the change renders with no code touch (CAT-04).

CSS lives in a `<style>` block inside `CatalogSection.astro` (scoped). No new global CSS needed
beyond what already exists in `sections.css` for the `.section-tag` and `.section-header` patterns
(reused as-is).
</objective>

    ```ts
    import EmptyState from './EmptyState.astro';
    interface CatalogItem { name: { es: string; en: string }; price: string; }
    interface CatalogCategory {
      id: string;
      category: { es: string; en: string };
      items: CatalogItem[];
    }
    interface Props {
      catalog: CatalogCategory[];
      lang: 'es' | 'en';
      emptyHeading: string;
      emptyBody: string;
      emptyTicketLabel: string;
    }
    const { catalog, lang, emptyHeading, emptyBody, emptyTicketLabel } = Astro.props;
    ```

    **Template:**
    Loop `catalog` — for each category:
    ```html
    <div class="catalog-category" data-category={category.id}>
      <div class="section-header reveal">
        <span class="section-tag">{category.category[lang]}</span>
        <h2 class="section-title">{category.category[lang]}</h2>
      </div>

      {category.items.length === 0 ? (
        <div class="reveal">
          <EmptyState
            heading={emptyHeading}
            body={emptyBody}
            ticketLabel={emptyTicketLabel}
          />
        </div>
      ) : (
        <ul class="catalog-rows reveal" aria-label={category.category[lang]}>
          {category.items.map((item) => {
            const isCotizar = item.price.toLowerCase() === 'cotizar';
            return (
              <li class="catalog-row">
                <span class="catalog-row__name">{item.name[lang]}</span>
                <span class={`catalog-row__price${isCotizar ? ' catalog-row__price--cotizar' : ''}`}>
                  {isCotizar ? 'Cotizar' : item.price}
                </span>
              </li>
            );
          })}
        </ul>
      )}
    </div>
    ```
