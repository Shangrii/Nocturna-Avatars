<interfaces>
Source to migrate verbatim: src/i18n/packages.json (both ES and EN slices)

Top-level schema (D-04):
  services.json
  ├── packages
  │   ├── tiers[]          ← 3 items (Penumbra/Umbra/Eclipse)
  │   │   ├── id           ← "penumbra" | "umbra" | "eclipse"  (string, no translation)
  │   │   ├── tier         ← {es, en}  e.g. {es: "Nivel I", en: "Level I"}
  │   │   ├── name         ← string    e.g. "Penumbra" (proper noun, no translation)
  │   │   ├── subtitle     ← {es, en}
  │   │   ├── price        ← string    e.g. "$40"  (no translation)
  │   │   ├── oneLiner     ← {es, en}
  │   │   ├── featured     ← boolean
  │   │   └── features[]   ← [{text: {es, en}, highlight: boolean}]
  │   ├── addons[]         ← [{name: {es, en}, price: string}]
  │   └── addonsNote       ← {es, en}
  └── catalog[]            ← category objects
      ├── id               ← "unity" | "blender" | "textures" | "accessories" | "extras"
      ├── category         ← {es, en}  (display name)
      └── items[]          ← []  (empty; staff populate once prices agreed — D-05)

Bilingual migration rule (D-02): for each translatable field, merge ES value + EN value into one
  object: { "es": "<ES text from packages.json>", "en": "<EN text from packages.json>" }
Non-translatable fields (id, name, price, featured, highlight) stay as flat values.

Category list (D-07, from CONTEXT.md):
  - { id: "unity",       category: { es: "Unity",          en: "Unity"        } }
  - { id: "blender",     category: { es: "Blender / Malla", en: "Blender / Mesh" } }
  - { id: "textures",    category: { es: "Texturas",       en: "Textures"     } }
  - { id: "accessories", category: { es: "Accesorios",     en: "Accessories"  } }
  - { id: "extras",      category: { es: "Extras / NSFW",  en: "Extras / NSFW"} }

      - `name`: copy verbatim (proper noun, no translation needed)

      - `price`: copy from either slice (same in both; "$40" / "$60" / "$90")
      - `oneLiner`: { "es": es.tiers[i].oneLiner, "en": en.tiers[i].oneLiner }
      - `featured`: copy from either slice (boolean)
      - `features[]`: for each feature, { "text": { "es": esFeature.text, "en": enFeature.text }, "highlight": feature.highlight }

    **IMPORTANT — current featured flag in packages.json:** Umbra is `featured: true` and Eclipse is
    `featured: false` in packages.json. The UI-SPEC §Featured Package Card says Eclipse has
    `featured: true`. Reconcile: set Eclipse `featured: true` and Umbra `featured: false` in
    services.json. This matches the UI-SPEC and ROADMAP success criterion 1 (Eclipse is the top
    tier). The packages.json has an inverted flag — correct it here.

    **packages.addons[]** — merge 8 add-ons:
      - `name`: { "es": es.addons[i].name, "en": en.addons[i].name }
      - `price`: copy from either slice (same in both; e.g. "+$5 USD")

    **packages.addonsNote** — { "es": es.addonsNote, "en": en.addonsNote }

    **catalog[]** — 5 categories, items: [] for each (D-05):
      Use the category list from the interfaces block above verbatim.

    Write the file with consistent 2-space indentation. Validate mentally that every translatable
    field is a `{es, en}` object and every non-translatable field is a flat value.

  <verify>
    <automated>node -e "
      const d = JSON.parse(require('fs').readFileSync('src/data/services.json','utf8'));
      // top-level keys
      if (!d.packages || !d.catalog) throw new Error('missing top-level keys');
      // tiers
      if (d.packages.tiers.length !== 3) throw new Error('expected 3 tiers');
      for (const t of d.packages.tiers) {
        if (typeof t.tier !== 'object' || !t.tier.es || !t.tier.en) throw new Error('tier bilingual missing: '+t.id);
        if (typeof t.subtitle !== 'object') throw new Error('subtitle not bilingual: '+t.id);
        if (typeof t.oneLiner !== 'object') throw new Error('oneLiner not bilingual: '+t.id);
        for (const f of t.features) {
          if (typeof f.text !== 'object' || !f.text.es || !f.text.en) throw new Error('feature text not bilingual: '+t.id);
        }
      }
      // eclipse featured
      const eclipse = d.packages.tiers.find(t => t.id === 'eclipse');
      if (!eclipse.featured) throw new Error('eclipse must be featured:true per UI-SPEC');
      // addons
      if (d.packages.addons.length !== 8) throw new Error('expected 8 addons');
      for (const a of d.packages.addons) {
        if (typeof a.name !== 'object') throw new Error('addon name not bilingual');
      }
      if (typeof d.packages.addonsNote !== 'object') throw new Error('addonsNote not bilingual');
      // catalog
      if (d.catalog.length !== 5) throw new Error('expected 5 catalog categories');
      for (const c of d.catalog) {
        if (!Array.isArray(c.items) || c.items.length !== 0) throw new Error('catalog items must be empty array: '+c.id);
        if (typeof c.category !== 'object') throw new Error('category not bilingual: '+c.id);
      }
      console.log('OK');
    " 2>&1</automated>
