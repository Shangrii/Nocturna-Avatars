  <behavior>
    Recurrence math (tz America/Mexico_City unless noted):
    - next_weekly_fire from a Wednesday 10:00 local, target weekday Monday 09:00 → the next Monday 09:00 local, returned as the correct UTC instant.
    - next_weekly_fire when the target weekday+time is later today → today; when already passed today → +7 days.
    - next_monthly_fire day=15 from the 20th → the 15th of next month; from the 10th → the 15th this month.
    - _clamp_day(2027, 2, 31) → 28; _clamp_day(2028, 2, 31) → 29 (leap); _clamp_day(2027, 4, 31) → 30; _clamp_day(2027, 1, 15) → 15.
    - next_monthly_fire day=31 landing in February clamps to the last February day.
    - next_oneoff_fire('2026-12-25','18','30') → 2026-12-25 18:30 local as UTC.
    - DST-boundary case: with a DST zone (e.g. 'America/New_York'), a weekly/monthly fire computed across the spring-forward boundary yields a valid UTC instant (no crash; hour offset consistent with the local wall time).
    Classification (D-13, grace default 6h, jitter 5m):
    - classify_fire(now == next_fire) → 'ontime'; now = next_fire + 2min → 'ontime'; now = next_fire + 2h → 'late'; now = next_fire + 7h → 'skip'.
    Validators:
    - parse_time('09:05') → (9,5); parse_time('9:5') accepted or rejected per a documented rule; parse_time('24:00') and parse_time('9') and parse_time('ab:cd') raise ValueError.
    - parse_date('2026-12-25') → date(2026,12,25); parse_date('2026-13-01') and parse_date('nope') raise ValueError.
    - valid_weekday(0) and valid_weekday(6) True; valid_weekday(7) and valid_weekday(-1) False.
    - valid_day_of_month(1) and valid_day_of_month(31) True; valid_day_of_month(0) and valid_day_of_month(32) False.
    - parse_emojis('✅ ❌') → ['✅','❌']; parse_emojis('a,b,c,d,e,f,g,h', cap=6) returns at most 6 items; empty/whitespace → [].
    Staff gate:
    - _is_staff(member with a REMINDERS_STAFF_ROLE_IDS role) True; member without → False; role-less member → False.
    schedule_summary returns a non-empty Spanish string distinguishing weekly vs monthly vs one-off (used later as the autocomplete label + listar line).
  </behavior>
