# Phase 4 — UI Design Contract

> Visual and interaction contract for the Gallery & Data Layer phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **Scope:** the masonry photo wall (`/galeria` · `/gallery`), the hand-rolled lightbox, and the landing featured grid (newest 6).
> **Grounding:** this is a brownfield phase. Every token below is READ FROM the existing "Refined Street Editorial" system (`src/styles/theme.css`, `sections.css`, `chrome.css`, `choreography.css`, `motion.css`). This spec does NOT introduce a parallel visual language — it composes the gallery inside the tokens that already ship.

## Spacing Scale

Uses the existing 8-point token scale from `theme.css` verbatim. No new spacing values are introduced.

| Token | Value | Gallery usage |
|-------|-------|---------------|
| `--space-3xs` | 4px | reveal travel unit; lightbox counter internal gap; caption-to-counter micro-gap |
| `--space-2xs` | 8px | swipe/nav icon inner padding; featured caption gap (n/a — no wall captions) |
| `--space-xs` | 12px | masonry gutter on mobile (< 768) |
| `--space-sm` | 16px | masonry gutter on tablet (768–1024); featured grid gap mobile |
| `--space-md` | 24px | masonry gutter on desktop (≥ 1024); featured grid gap desktop; lightbox chrome inset |
| `--space-lg` | 32px | lightbox caption/counter block bottom inset; featured section header spacing |
| `--space-xl` | 48px | space above the "View full gallery" link |
| `--space-2xl` | 64px | major block break (inherits section rhythm) |
| `--space-3xl` | `clamp(60px,10vw,120px)` | `--section-pad` — vertical section padding (inherited, unchanged) |
| `--page-gutter` | `clamp(20px,4vw,48px)` | horizontal page inset for wall + featured (inherited) |

**Exceptions:** Lightbox navigation and close controls MUST meet the 44px `--touch-min` target even when the visible icon is smaller (mirrors existing `.dc-dismiss` / `.card-cta` `min-height: var(--touch-min)`). Masonry gutter and column count are responsive (see Layout Contract) but every discrete value above is a token multiple of 4.

## Color

The gallery inherits the editorial ink/paper rhythm. Red stays a surgical accent — in this phase it appears in only three places: the section tag/eyebrow (existing), the lightbox counter/active affordance, and focus-visible outlines. Photos supply the visual richness; chrome stays disciplined.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-ink` `#0a0c14` | `/galeria` wall field + featured section field (default ink section) |
| Secondary (30%) | `--color-ink-raised` `#10131e` | tile placeholder/aspect-box background before image paints (CLS-free); lightbox stage surface |
| Overlay scrim | `rgba(4,5,10,0.88)` + `blur(8px)` | lightbox backdrop — reuse `.dc-overlay` verbatim |
| Accent (10%) | `--color-red` `#c0192c` (fills/rules) · `--color-red-on-ink` `#e84a5e` (small text on ink) | see reserved-for list |
| Border / hairline | `--color-border` (`#fff` @ 6%) | tile hairline (optional), lightbox chrome dividers |
| Foreground text | `--color-white` `#f0eae4` / `--color-white-dim` `#9a9198` | lightbox caption (dim), counter (white) |

**Accent (red) reserved for — explicit list (never "all interactive elements"):**
1. The section tag/eyebrow marker on the gallery + featured headers (`.section-tag`, existing — `--color-red-on-ink`).
2. The lightbox counter separator emphasis is NOT red — counter is off-white; red is used only for the **active/hover state of the lightbox prev/next/close controls** and their `focus-visible` outline.
3. `focus-visible` outlines on all interactive gallery elements (tiles, featured tiles, lightbox controls) — `2px solid var(--color-red)` `outline-offset: 2px` (mirrors `.dc-open-btn:focus-visible`).
4. The `.link-arrow` red bottom-border on the "View full gallery" link (existing component behavior).

**No destructive color in this phase.** There are no destructive user actions on the site side (photo removal happens in Discord via the Phase 5 bot, never in the browser). The `Destructive` role is intentionally unused.

**Contrast (AA):** captions/counter/controls all sit on the dark lightbox scrim → off-white on `rgba(4,5,10,0.88)` clears AA comfortably. On the ink wall, `--color-red-on-ink` (not brand red) is used for any small red text per the existing A11Y token split.

## Layout Contract — Masonry Wall (`/galeria` · `/gallery`)

Replaces the `EmptyState` body in `GalleryPage.astro` with the data-driven wall. The `EmptyState` is retained ONLY as the empty-`gallery.json` fallback (D-12).

**Focal point:** the photo wall itself is the sole visual anchor of `/galeria` — the photos ARE the content. Chrome (header, controls, hairlines) stays deliberately quiet so nothing competes with the imagery: tiles carry no text (D-12), surfaces are squared with no decorative framing, and red is held to the surgical accents listed in Color. On the landing, the featured grid is the anchor of its own block; every other element (eyebrow, "View full gallery" link) is subordinate to the images.

| Property | Mobile (375–767) | Tablet (768–1023) | Desktop (1024–1439) | Wide (≥ 1440) |
|----------|------------------|-------------------|---------------------|---------------|
| Columns | 2 | 3 | 4 | 4 |
| Gutter | `--space-xs` (12px) | `--space-sm` (16px) | `--space-md` (24px) | `--space-md` (24px) |
| Container | full-bleed within `--page-gutter` | same | same, `max-width: 1440px` centered | `max-width: 1440px` centered |

- **Masonry driver:** Masonry.js (desandro) + imagesLoaded (D-10). `columnWidth`/`gutter` computed from the breakpoints above; `percentPosition: true` so columns are fluid.
- **CLS-free (D-04):** every tile is an aspect-ratio box using stored `width`/`height` → `aspect-ratio: {width} / {height}` on the tile, and `<img width height>` set on the element. The `--color-ink-raised` placeholder fills the box until the image decodes so no layout shift and no flash of empty space.
- **Tile radius:** 0px (editorial system uses squared surfaces + hairline). Optional 1px `--color-border` hairline frame — executor discretion; default is no frame (photos define their own edges).
- **Tiles carry NO visible caption** (D-12). Natural aspect ratio preserved (that is the point of masonry).
- **Lazy loading (D-09):** `loading="lazy"` + `decoding="async"` on every image EXCEPT the first row (first `N`=column-count images load eagerly to fill the fold fast).
- **Alt text (D-03):** `alt = caption` when present; else the generic localized fallback string (see Copywriting Contract). Never an empty `alt`.
- **Render-all (D-11):** all entries render, newest-first by `date` (D-05). No pagination.
- **Hover state (desktop, `@media (hover:hover)` only):** subtle scale `transform: scale(1.02)` + brightness lift over 0.3s ease; cursor `zoom-in`. Neutralized under `prefers-reduced-motion`.
- **Tile as button:** each tile is a real `<button>` (or `<a>` with JS) so it is keyboard-focusable and Enter/Space opens the lightbox at that index. `focus-visible` → red outline.

### Reveal choreography (tiles)
- Reuse the existing `.reveal` system (`motion.css` + the Phase 2.1 controller): initial `opacity:0; translateY(--space-md)` behind `.motion-ready`, animated in on scroll.
- **Stagger:** tiles reveal with a small incremental delay (≈ 40–60ms per tile, capped so late tiles don't lag) — consistent with other Phase 2.1 reveals.
- **Ordering caveat:** stagger must key off DOM/visual order and must NOT fight Masonry's absolute positioning — reveal runs AFTER imagesLoaded + Masonry layout settles (so tiles fade in already in their final position, never mid-reflow).
- **Reduced motion:** `prefers-reduced-motion` → tiles appear at full opacity, no travel, no stagger (guaranteed by the existing `.reveal` reduced-motion rule; the JS stagger is skipped). Layout still settles CLS-free.

## Interaction Contract — Lightbox

Hand-rolled (D-13), built on the existing `dc-overlay` / `dc-modal` + focus-trap pattern (reuse `chrome.ts` Escape/outside-click handlers; mirror the XSS-safe `createElement` + `textContent` rendering from CartSummaryModal / CartDrawer). NOT PhotoSwipe/GLightbox.

### Structure & layout
| Element | Contract |
|---------|----------|
| Backdrop | reuse `.dc-overlay` verbatim: `rgba(4,5,10,0.88)` + `blur(8px)`, `z-index: 10000`, fade 0.35s ease |
| Stage | full-viewport centered image; image `max-width: 92vw` (mirrors `.dc-modal max-width`), `max-height: ~86vh` so caption + counter fit below; `object-fit: contain`; background `--color-ink-raised` behind the contain letterbox |
| Radius | image/frame 0px (editorial); backdrop full-bleed |
| Chrome inset | `--space-md` from viewport edges for controls; caption/counter block `--space-lg` bottom inset |

### Controls
| Control | Placement | Visual | Hit target | State |
|---------|-----------|--------|------------|-------|
| Close (✕) | top-right | inline SVG stroke `currentColor`, off-white | 44px (`--touch-min`) | hover → red; `focus-visible` → 2px red outline |
| Prev (‹) | left edge, vertically centered | inline SVG chevron | 44px | hover → red; disabled visual only if NOT looping — but we LOOP (D-14) so never disabled |
| Next (›) | right edge, vertically centered | inline SVG chevron | 44px | hover → red |
| Counter | bottom, above/beside caption | `3 / 24` — mono 12px, tabular-nums, off-white, `letter-spacing: 0.18em`, uppercase | — | live-updates on nav |
| Caption | bottom, under counter | Inter 15px, `--color-white-dim`, line-height 1.5, max-width ~60ch, centered | — | hidden entirely when caption absent (counter still shows) |

### Behavior (D-14 — full polish)
- **Open:** clicking/Enter/Space on a wall tile OR a featured tile opens the lightbox at that image's index. Set `aria-hidden`/`inert` on background, trap focus inside the lightbox (reuse the Phase 3.1 focus-trap), move focus to the Close button.
- **Loop:** Next past the last wraps to first; Prev before the first wraps to last (D-14).
- **Counter:** always `currentIndex+1 / total`.
- **Neighbor preload (D-14):** on open and on every nav, preload `index±1` images (`new Image().src`) so navigation is instant.
- **Close triggers:** Escape key, backdrop click (outside the image/controls), the ✕ button, and swipe-down on touch. On close: restore `aria-hidden`, release focus trap, return focus to the tile that opened it.
- **Keyboard:** ← / → navigate; Esc closes; Tab cycles Close → Prev → Next → (Close) within the trap.
- **Mobile swipe (D-14):** horizontal swipe navigates (left = next, right = prev); vertical swipe-down closes. Use a pointer/touch threshold (~50px) to distinguish intent; horizontal drag can track the image with a light translate for feedback.
- **Body scroll lock:** add `data-lenis-prevent` on the overlay (matches `.cart-modal-overlay`) so Lenis smooth-scroll is paused while open.
- **Swap safety:** the lightbox + Masonry init are mounted on the View Transitions lifecycle (`initMotion`/`astro:page-load`), torn down on `astro:before-swap` — same pattern as all Phase 2/3 scripts (a new `src/scripts/gallery.ts`, executor discretion).

### Motion + reduced-motion
- **Entrance/exit:** reuse `.dc-overlay`/`.dc-modal` transitions — overlay opacity 0.35s ease; the image stage may add a gentle `translateY(24px) scale(0.97)` → rest (mirrors `.dc-modal`).
- **Nav transition:** cross-image change may use a ~150–200ms opacity/slide; MUST be neutralized (instant swap) under `prefers-reduced-motion`.
- **Reduced motion:** no entrance/nav animation, no swipe-track translate feedback; the lightbox still opens/navigates/closes fully functionally (mirrors the existing `.dc-overlay`/`.dc-modal` reduced-motion rule in `chrome.css`). All behavior stays reachable — only motion is removed.

## Layout Contract — Featured Grid (landing, GAL-04)

Replaces the current `featured` `Teaser` placeholder in `index.astro` (D-16). The secondary `gallery` teaser (link-out) stays as-is. Sits in the landing order: hero → **featured** → about+process → packages → gallery teaser → closing.

| Property | Mobile (375–767) | Desktop (≥ 768) |
|----------|------------------|-----------------|
| Layout | responsive CSS grid, **2-up** | **3-up** |
| Gap | `--space-sm` (16px) | `--space-md` (24px) |
| Item count | newest **N = 6** by `date` (D-15) | newest **6** |
| Tile aspect | uniform square-ish crop (`aspect-ratio: 1 / 1`, `object-fit: cover`) — this is a curated grid, NOT masonry (D-16), so tiles are cropped for rhythm |
| Radius | 0px (editorial) | 0px |

- **Auto-curated (D-15):** featured = first 6 after sorting `gallery.json` newest-first. No `featured` flag, no manual list.
- **Click behavior (D-16):** clicking a featured tile **opens the lightbox in place** (index = that tile within the featured set, or into the full set — executor picks; keeping the visitor on the landing near the CTA is the goal). Tiles are focusable `<button>`s, same a11y contract as wall tiles.
- **"View full gallery" link (D-16):** a separate `.link-arrow` (reuse existing component) below the grid, `--space-xl` above it, → `localizedPath('gallery', lang)`. This is the ONLY navigation-away affordance in the featured block.
- **Reveal:** the grid uses the `.reveal` system; featured tiles may share the wall's stagger (lighter — only 6 tiles).
- **Empty state:** if `gallery.json` has < 1 entry, the featured block falls back to the branded `EmptyState` with the gallery `linkLabel`/`linkHref` (never renders a broken/empty grid).
- **Fewer than 6 entries:** render however many exist (1–5) in the same grid; never pad with placeholders.

## Accessibility Contract

- Every tile (wall + featured) is a focusable control; Enter/Space opens the lightbox; `focus-visible` → 2px red outline `offset 2px`.
- Lightbox is a proper `role="dialog"` `aria-modal="true"` with `aria-label` = `lightbox.dialogLabel`; focus is trapped and restored on close (reuse Phase 3.1 focus-trap).
- All lightbox controls have bilingual `aria-label`s (table above); counter exposes `lightbox.counterLabel` to AT.
- `alt` is never empty — caption or generic fallback.
- All motion respects `prefers-reduced-motion` (tile reveal/stagger, hover scale, lightbox entrance + nav, swipe feedback).
- Contrast AA in both ink wall and on the lightbox scrim; small red text uses `--color-red-on-ink`.
- Responsive verified at 375 / 768 / 1024 / 1440 (column counts + gutters per Layout Contract).
