<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gallery.json `caption` → featured `<img alt>` + lightbox DOM | Discord-authored caption is rendered as alt on the featured tiles and (via the reused Plan 02 lightbox) into the lightbox caption node — untrusted input, the phase's headline threat. |
| bot-appended entries → newest-6 slice | The featured set is derived purely from `date` ordering; a malformed/missing `date` could misorder or drop an entry from the featured slot. |
| shared overlay on two pages → gallery.ts | One controller now drives an overlay on both the landing and /galeria; it must re-query the live overlay per page and not leak listeners across View Transitions swaps. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07 | Tampering (DOM XSS) | featured `<img alt>` + reused lightbox caption fed by Discord `caption` | mitigate | Featured alt is set through Astro `.astro` auto-escaping only — never `set:html`; the in-place lightbox reuses Plan 02's `createElement` + `textContent` path (never `innerHTML`). Verify grep shows no `set:html` in FeaturedGallery.astro and no `innerHTML`/`set:html` in gallery.ts. A malicious caption stays inert text. |
| T-04-08 | Denial of Service (layout) | missing/renamed `file` → 404 featured image | accept | A missing `file` degrades to the `--color-ink-raised` square placeholder + alt (fixed `aspect-ratio:1/1` so no reflow); no data leak, no broken landing. |
| T-04-09 | Elevation / state leak | shared overlay + document listeners across landing↔gallery swaps | mitigate | gallery.ts binds document listeners once behind a module flag and re-queries the live `.dc-overlay.lightbox` at event time (Plan 02 lifecycle); the `astro:before-swap` teardown from Plan 02 still fires — no duplicate handlers accumulate when navigating landing → /galeria. |
| T-04-SC | Tampering (supply chain) | masonry-layout / imagesloaded | mitigate | No new deps in this plan; versions pinned + `npm audit` clean in Plan 01. Featured grid is pure CSS (no Masonry), so it adds no third-party surface. |
</threat_model>
